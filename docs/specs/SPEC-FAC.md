## 0. 結論（先看這裡）

1. **第一批三條，照依賴排 1a、1b、1c。**
   - **1a 懸壺社**（採藥、煉藥）：只用現有系統，加差事、階級、4 個新藥方。最先做，順便把框架做出來。
   - **1b 窯幫＋洪爐會**（採礦、打鐵）：窯幫只加差事與礦脈；洪爐會要新系統「打造」。
   - **1c 山獵盟＋皮匠行**（打獵、皮料）：要一個野外據點與一棟新建築，等地圖新點開放。
2. **三條的循環一樣**：採或做 → 交差事 → 聲望 → 升階 → 新配方與好價錢。
3. **現況的洞**（已對程式確認）：配方只有 5 個、全是消耗品；礦石只能賣，沒有打造；採藥、挖礦、煉藥的熟練度只給機率加成，沒有人收貨、沒有東西可解鎖。
4. **待 mumi 定 5 題**，見第 6 節。

## 3. 1b 窯幫＋洪爐會（採礦、打鐵）

藍圖裡這是兩個勢力：窯幫採礦、把礦賣給洪爐會；洪爐會打鐵。建議做成**兩個行會、一條上下游**，可以只入一個，兩個都入最順。見題 2。

### 3.1 窯幫

**入口**：老礦工（現有 NPC，目前在鎮上當路人，改成入口職位）；窯礦坡的窯口（新點，地圖開放後補第二個入口）。

**階名〔暫名〕**：窯工（外圍）→ 把頭（正式）→ 窯頭（核心）。

| 關 | 條件 |
| --- | --- |
| 入門考驗 | 交粗鐵 ×6 |
| 升把頭 | 聲望 12；功績：在赤石廢礦挖到玄石 ×1 交回 |
| 升窯頭 | 聲望 36；在會 30 日；功績：帶回沼鐵 ×4 與赤銅 ×4（跑兩處礦） |

| 階 | 價錢 | 技藝 | 門路 |
| --- | --- | --- | --- |
| 窯工 | 鐵鋪收購礦料 +10% | — | 供料差事（粗鐵、赤銅、沼鐵、玄石） |
| 把頭 | 收購 +15% | 「土法探礦」：赤石廢礦多一處礦脈（鐵脈上限 +1） | 得知一處私礦口（新採集點，赤銅 ×2） |
| 窯頭 | 收購 +20% | 挖礦疲累 −20%；落石不傷 | 私礦的貨可以走窯幫賣，不經稅卡（接 SPEC-03，等黑市實作） |

### 3.2 洪爐會

**入口**：灰窯鎮石記鐵鋪（`hy_smith`）、渡陰關軍械坊（`dy_smith`），都是現有建築。

**階名〔暫名〕**：爐丁（外圍）→ 匠徒（正式）→ 爐匠（核心）。

| 關 | 條件 |
| --- | --- |
| 入門考驗 | 交粗鐵 ×4 與赤銅 ×2，並在鋪裡幫工 4 小時（疲累照挖礦算） |
| 升匠徒 | 聲望 12；功績：累計幫工 20 小時 |
| 升爐匠 | 聲望 36；在會 30 日；功績：親手打一件良品（藍）交給會裡 |

### 3.3 新系統「打造」（洪爐會的技藝）

現況礦石只能賣。打造讓礦石有去處，也讓裝備多一個來源。

| 項目 | 規則（初值） |
| --- | --- |
| 在哪 | 鐵鋪與軍械坊；匠徒以上才能用爐 |
| 能打什麼 | 該鋪貨架上有的基底（石記鐵鋪 5 種、軍械坊 9 種） |
| 材料 | 粗鐵數＝`max(2, round(店價 ÷ 12))`；赤銅、沼鐵各抵 2 塊粗鐵 |
| 工時 | 2 小時，疲累照挖礦 |
| 爐火費 | 3 兩；爐匠免 |
| 成品品質 | 匠徒：白 80%、良品 20%。爐匠：白 50%、良品 40%、稀有 10% |
| 加玄石 | 多放 1 塊玄石，品質往上移一檔的機率 +15% |
| 成品 | 已鑑定（自己打的不用鑑） |

手算：短刃店價 30，材料粗鐵 3（渡陰關收購值 24、灰窯鎮 12）＋爐火費 3，成本約店價的 50–90%，視礦從哪來。自己挖的礦等於省下全部材料錢。待驗算 F-2。

爐匠另有「百煉」：拿一件已有詞綴的裝備加玄石 ×2，重骰其中一條詞綴的數值（不換詞綴種類）。做不做見題 3。

| 階 | 價錢 | 技藝 | 差事 |
| --- | --- | --- | --- |
| 爐丁 | 鐵鋪買價九折 | — | 供料；幫工（在場 4 小時，銀 8、聲望 +1） |
| 匠徒 | 買價八五折 | 打造 | 訂製（打指定基底交件） |
| 爐匠 | 買價八折 | 良品與稀有機率、爐火費免、百煉 | 軍械訂單（交件給破曉軍需帳，破曉聲望 +1） |

要不要加新熟練度「打鐵」見題 4。

## 4. 1c 山獵盟＋皮匠行（打獵、皮料）

**前置**：地圖開放灰窯原新點（山獵盟的獵棚在枯骨獸徑，是野外據點）；灰窯鎮加一棟皮匠鋪。兩樣都還沒有，所以排第三。

### 4.1 山獵盟

**入口**：枯骨獸徑的獵棚（新點，職位「獵頭」）；破曉營軍需帳可代收皮料與代轉差事（第二入口，現有建築）。

**階名〔暫名〕**：跟獵（外圍）→ 獵手（正式）→ 老獵（核心）。

| 關 | 條件 |
| --- | --- |
| 入門考驗 | 交獸皮 ×4 |
| 升獵手 | 聲望 12；功績：獵一頭山豬並帶回完整獸皮 ×1 |
| 升老獵 | 聲望 36；在會 30 日；功績：帶回異獸內丹 ×1 |

| 階 | 價錢 | 技藝 | 差事 |
| --- | --- | --- | --- |
| 跟獵 | 獸皮、生肉收購 +10% | — | 供料（獸皮、生肉）；獵殺（狼、山豬） |
| 獵手 | 收購 +15% | 「設陷」：在野外花 1 小時布陷，下一場狩獵戰敵人開場失衡 | 指定獵物（附地點） |
| 老獵 | 收購 +20%；內丹 +25% | 陷阱可留到隔天收一份生肉與獸皮；追蹤與剝皮熟練成長 +25% | 異獸獵單；獸潮前的預警 |

**敵對**：合獸門（藍圖：死敵）。入了山獵盟就不能入合獸門，反之亦然。

### 4.2 皮匠行

**入口**：灰窯鎮皮匠鋪（新建築，職位「皮匠」）。

**階名〔暫名〕**：學徒（外圍）→ 皮匠（正式）→ 老師傅（核心）。

| 階 | 技藝 |
| --- | --- |
| 學徒 | 供料差事（獸皮、完整獸皮） |
| 皮匠 | 「硝皮」：獸皮 ×3 → 熟皮 ×1；用熟皮訂製皮甲、皮靴、皮手套（基底同現有輕甲類） |
| 老師傅 | 用完整獸皮做的皮件必為良品；可做行囊（行旅皮囊） |

皮匠行的數字等 1b 的打造驗算完再比照訂，這裡不另列。
