## 0. 結論（先看這裡）

1. **第一批三條，照依賴排 1a、1b、1c。**
   - **1a 懸壺社**（採藥、煉藥）：只用現有系統，加差事、階級、4 個新藥方。最先做，順便把框架做出來。

   - **1c 山獵盟＋皮匠行**（打獵、皮料）：要一個野外據點與一棟新建築，等地圖新點開放。
2. **三條的循環一樣**：採或做 → 交差事 → 聲望 → 升階 → 新配方與好價錢。
3. **現況的洞**（已對程式確認）：配方只有 5 個、全是消耗品；礦石只能賣，沒有打造；採藥、挖礦、煉藥的熟練度只給機率加成，沒有人收貨、沒有東西可解鎖。
4. **每條行會分四層做深**（1.1 節）：這一批做第一層「差事與階級」加第二層「專屬玩法」各一樣；第三、四層之後往上加，不用回頭改框架。
5. **已定 2 題、待定 4 題**，見第 6 節。

### 2.5 專屬玩法：行醫（第二層）

藥做出來不只是賣，還能拿去治人。這讓「身上該備哪幾種藥」變成要想的事。

| 項目 | 規則（初值） |
| --- | --- |
| 在哪 | 三個入口各有「病患」名額：回春藥鋪 2、藥攤 1、傷兵帳 3；每日 00:00 補滿 |
| 誰能做 | 社徒以上。採藥人只能在旁邊看（看得到症狀，不能下藥） |
| 怎麼做 | 點病患 → 看到 1–2 個症狀 → 從行囊選一份藥給他。花 0.5 小時 |
| 症狀與對的藥 | 外傷流血→止血散；失血虛弱→金創藥水或回春丹；中毒→解毒丸或祛瘴丸；疲病→提神湯藥；寒傷→驅寒湯 |
| 對症 | 藥被用掉；得診金（該藥收購價 × 1.5）、聲望 +1、輕善（接善惡系統後才計） |
| 不對症 | 藥被用掉、沒有效果、沒有診金；同一個病患當天不能再試 |
| 兩個症狀 | 要兩份對的藥都給才算治好，診金與聲望各算兩次，另加聲望 +1 |
| 症狀從哪來 | 平常外傷與疲病為主；獸潮期間與結束後 2 日，傷兵帳名額 ×2、外傷居多；冬季寒傷居多；渡陰關藥攤中毒較多（靠腐骨沼） |
| 藥師加成 | 看得出「重症」（要用回春丹），治好聲望 +3 |

接口：症狀表是資料，之後加蠱傷、屍毒只要加一列；病患數量由世界狀態的修正器決定（第三層事件直接掛上來）。
