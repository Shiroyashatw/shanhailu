## 0. 結論（先看這裡）

1. **身分不少：可以加入的有 35 種，另有 6 條「派內的路」。** 全表在第 2 節。灰窯原內就摸得到入口的有 30 種以上。
2. **由小到大做，分五級。** 生計行會 → 行腳與祭祀 → 大勢力 → 從軍 → 邪路。越後面依賴越多（通緝、善惡、黑市、獵令、地圖新點）。
3. **框架只做一次，所有身分共用。** 三階（外圍、正式、核心）＋兩種身分槽：軍、大勢力、邪派共用一個「正式身分」槽；行會與小勢力放「行會」槽，可以兼任（藍圖 11.8.3）。
4. **每個身分都給同一種循環**：做這門營生的事 → 交差事 → 累積該勢力的聲望 → 升階 → 解鎖技藝、配方、服務與更好的價錢。這就是採藥、挖礦、打獵現在缺的「目標」。
5. **第一批只做三條生計行會**（懸壺社、窯幫＋洪爐會、山獵盟＋皮匠行），因為它們只用到現有系統，不必等通緝與地圖。細節見 `SPEC-FAC.md`。
6. **先訂框架，再一層層加深。** 每個身分分四層（3.8 節）；框架第一版就留好接口，之後加玩法是加資料與掛鉤，不用回頭改框架。
7. **把世界串起來。** 每樣東西都有明路與暗路，流到誰手上就改變誰（3.9 節）。明路先上，暗路跟善惡、通緝、黑市同時上。
8. **已定 2 題、待定 6 題**，見第 9 節。

## 3. 三階框架

所有身分都用同一套三階。各勢力只換稱呼與門檻數字。

| 階 | 意思 | 共通內容 |
| --- | --- | --- |
| 無 | 還沒加入 | 只能照現況買賣、接委託板 |
| 外圍 | 過了入門考驗 | 能接這個勢力的差事；收購價較好；不佔正式身分槽 |
| 正式 | 被收為自己人 | 第一批技藝或配方；店內折扣；專屬差事。軍、大勢力、邪派在這一階佔用「正式身分」槽 |
| 核心 | 這門營生的老手 | 招牌技藝；特殊服務；可擔保別人。之上的首領是職位，另案（SPEC-NPC-B） |

### 3.1 兩種身分槽（藍圖 11.8.3）

- **正式身分槽，只有 1 個**：第 3、4、5 級共用。升「正式」那一刻佔用；外圍不佔。互為死敵的派連外圍也不能同時掛（藍圖 12.2）。
- **行會槽，可以兼任**：第 1、2 級。兼任幾個見第 9 節題 1。
- 兩種槽互不干擾：可以同時是破曉正式成員、懸壺社藥師、洪爐會爐丁。
- 例外由各勢力的 `enemies` 欄決定：義莊成員不能入屍傀門、發丘門；山獵盟成員不能入合獸門。

### 3.2 加入

1. **找到入口**：每個勢力至少 2 個入口職位，一個出缺另一個仍能引薦（藍圖 12.3）。
2. **入門考驗**：一件該勢力的差事（生計行會是交一批貨；邪派是投名狀）。
3. 過了就是外圍，聲望從現值起算（現有三個勢力沿用已累積的聲望）。

### 3.3 升階

升階要同時滿足四項，缺一不可：

| 條件 | 說明 |
| --- | --- |
| 聲望達門檻 | 該勢力的 `S.rep[f]`；只增不減（現況規矩） |
| 一件指定功績 | 每階一件，寫在各勢力的表裡；做完才能提出升階 |
| 在派天數 | 外圍 → 正式不設；正式 → 核心要滿一段時間 |
| 善惡段符合 | 第 1、2 級多數不看；第 3 級以後照藍圖 9.3、12.2 的表 |

升階由入口職位辦理，不自動跳。玩家要自己走回去提。

### 3.4 差事

差事是各勢力自己發的工作，跟委託板分開。

| 欄位 | 說明 |
| --- | --- |
| 來源 | 該勢力的入口職位；每個入口每天備 2 張，每日 00:00 刷新 |
| 種類 | 供料（交材料）、訂製（交成品）、外勤（送、護、獵、查）、營生（在場做工 N 小時） |
| 期限 | 預設 3 日；逾期作廢，不扣聲望（生計行會）或扣（軍與邪派，各自定） |
| 報酬 | 銀兩＋聲望。銀兩比委託板同類略低，差額換成聲望 |
| 同時上限 | 每個勢力同時 2 張；與委託板的上限分開算 |
| 階級限制 | 每張差事標最低階；高階差事報酬與聲望都較高 |

### 3.5 好處的給法

每一階固定給四類中的幾樣，數字各勢力自己定：

1. **價錢**：賣給自家店的收購價加成、買價折扣。
2. **技藝**：新配方、新招式、新動作（例如打造、設陷）。
3. **服務**：自家設施免費或半價（藥爐、診療、鑑定、借宿）。
4. **門路**：別人拿不到的差事、貨、消息或通行。

### 3.6 脫離與轉投

| 身分 | 脫離 | 再加入 |
| --- | --- | --- |
| 行會（第 1、2 級） | 隨時可退，無代價；聲望保留 | 重做一次入門考驗，回到外圍；滿足條件可直接提升階 |
| 大勢力（第 3 級） | 要回入口辦；退後 30 日內不能入別的大勢力 | 聲望保留，階級重來 |
| 軍（第 4 級） | 服役期滿才能退；提前走＝逃兵，交通緝（SPEC-MIL） | 逃兵不能再入同一軍 |
| 邪派（第 5 級） | 等於背叛，各派處置不同（藍圖 12.7） | 不能 |

### 3.7 敵對

加入某勢力後，它的死敵對你的態度跟著變。這走「勢力敵意」，不走善惡（藍圖 9.2：善惡看傷害了誰，不看得罪了誰）。第 1 級行會幾乎沒有敵對；第 2 級起各勢力在表裡列 `enemies`。

### 3.8 四層深度與延伸接口

每個身分都照同一個四層結構長大。第一批只做前兩層，但框架要讓後兩層「加資料就能接」。

| 層 | 是什麼 | 什麼時候做 |
| --- | --- | --- |
| 一 差事與階級 | 交貨、訂製、外勤；三階、價錢與服務 | 第一批 |
| 二 專屬玩法 | 這個身分獨有的一個小系統（行醫、打造、探脈、設陷…） | 第一批，每個身分至少一樣 |
| 三 事件與糾葛 | 世界狀態改變這個身分的需求；勢力之間的恩怨要玩家選邊 | 動態事件與時間骨幹上線後 |
| 四 路的盡頭 | 核心階之後：帶人、管一處據點、轉進更大的勢力 | 首領職位與其他區開放後 |

框架第一版必須留的接口：

| 接口 | 用途 |
| --- | --- |
| 差事種類可擴充 | 每種差事是一個處理器（產生、檢查完成、結算），新種類登記就能用，不改主流程 |
| 專屬動作登記 | 每個身分可以在指定建築或地點掛自己的動作鈕，依階級顯示 |
| 階級查詢 | `rankOf(f)`、`hasRank(f, n)`，配方、貨架、對話、差事都用這一個函式判斷 |
| 修正器 | 差事數量、病患數量、收購價這類數字都經過修正器，事件只要掛修正器就能改 |
| 功績旗標 | `S.ident.*.feats` 記做過的事，升階、對話與之後的事件都查它 |
| 事件掛鉤 | 用時間骨幹的 `Time.on`（每日、換季）與世界事件（獸潮開始／結束），不各自計時 |
| 買主表 | 每樣貨列買主、立場、價格倍率、後果標籤（聲望、善惡、世界數字、行規）；見 3.9 |
| 落款欄 | 玩家製品的記號（藥印、匠印）與「不落款」選項；見 3.9 |
| 行規欄 | 每個身分的禁忌與被發現的處置；見 3.9 |

### 3.9 串連：每樣東西都有明路與暗路（方向已定 01:00）

目標是把世界串起來：玩家做出來、採回來的東西，要流到別的勢力手上，並且改變那個勢力與那個地方。每個身分都照下面七條設計。

1. **三種去處。** 每樣可做、可採的東西至少有三類買主：正（自家行會、破曉、救濟）、灰（官營、稅卡、私賣）、黑（匪、邪派、鬼市）。黑的出價最高，後果也最重。
2. **去處會改變世界。** 買主拿到貨之後，活世界的數字跟著動（SPEC-01 的繁榮、治安、駐軍、匪勢）：兵器賣給斷路幫，匪勢上升、路更險；傷藥送進傷兵帳，獸潮比較守得住。本檔只定方向，幅度交數值對 SPEC-01 驗算。
3. **後果要看得見。** 不只是數字：你打的刀會出現在攔路的匪手上；你賣的假藥讓病患隔天還躺著；你供的藥讓傷兵帳少幾張空床。
4. **落款。** 玩家做的東西帶「落款」（藥印、匠印），沿用 SPEC-03 2.1 的物品記號欄位，新增一種記號。貨在黑買主那裡被搜出來（玩家或官府清剿、稅卡查驗），有落款就追得到你。可以選「不落款」：賣價打八折，但查不到你。
5. **行規。** 每個行會有幾條禁忌（懸壺社不得製毒害人、山獵盟不得賣活獸給合獸門…）。犯了沒被發現：行會不知道，但善惡照算（藍圖 9.2：沒人看見也算，輕一半）。被發現：除名，並照 SPEC-02 計善惡與通緝。
6. **自己用。** 做出來的東西也能自己拿去做事，好事壞事都行：迷藥放倒守墓人、毒藥辦殺手單、捕獸夾抓活獸。每樣東西在表裡列「能對誰用、在哪用」。
7. **需求由世界產生。** 各勢力缺什麼，看世界狀態：獸潮前破曉缺兵器與傷藥、匪勢高時斷路幫收刀、冬天到處缺驅寒湯。缺口變成差事（明路）或鬼市黑單（暗路）。

**硬性寫法（不隨選項改）：**
- 迷藥只用於偷、劫、綁、脫身、盜墓這類情境；**不得與青樓消費或任何性內容相連**，沿用 `brothel-business-v0.3.md` 的硬性寫法。
- 綁人、賣人一律走販人線（藍圖 12.5.1、SPEC-03 第 8 節），重惡，不另開捷徑。
- 投毒於水井、糧倉這類害一整群人的做法屬重惡的最高一級，照 SPEC-02 的死刑線辦。

**先後：** 暗路沒有善惡與通緝就等於白賺，所以**明路先上；暗路跟「善惡、通緝、黑市」那一包同時上**。框架第一版就把買主表、落款欄、行規欄留好，暗路上線時只加資料。

## 6. 節奏目標（驗算依據）

以下是設計目標，不是量測結果：

| 項目 | 目標 |
| --- | --- |
| 行會外圍 → 正式 | 專心做約 8–10 個遊戲日 |
| 行會正式 → 核心 | 再約 25–30 個遊戲日（約一季） |
| 同時兼兩個行會 | 各自慢約一倍；時間是唯一的限制 |
| 差事的銀兩 | 每小時收入不高於同階段委託板的 0.8 倍；差額用聲望與解鎖補 |
| 升到核心後 | 靠自家配方與折扣，每小時收入比沒入會高約 20–30% |

## 7. 驗收條件（草案，供之後 ACC 對照）

1. 沒入會時，遊戲行為與現況完全相同。
2. 入門考驗過後成為外圍，「身分」欄與行會列正確顯示。
3. 聲望達標但功績沒做，不能升階；功績做了但聲望不足，也不能。
4. 兩個行會可以同時在會，差事清單各自獨立。
5. 佔了正式身分槽後，別的大勢力、軍、邪派的升正式會被拒，文字說明原因。
6. 行會退會無代價、聲望保留；再入要重做入門考驗。
7. 差事每日 00:00 刷新；逾期作廢。
8. 舊存檔讀得進來，身分為平民、無行會。
9. 既有六套 e2e 全過。
