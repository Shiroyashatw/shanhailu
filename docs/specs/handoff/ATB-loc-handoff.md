## 1. 三種語意

- **甲＝按本人出手**：從該單位自己的下一次出手算起，數他自己出手幾次。
- **乙＝按拍**：固定長度的戰鬥時間，全場共用，與誰出手快慢無關。**1 拍＝10 刻＝一名速度 10 的單位出手一次的時間。**
- **丙＝按全場**：整場有效。

## 4. 名詞機制定義

| 名詞 | 機制定義 |
| --- | --- |
| 行動條 | 每個單位自己的進度 0–100；速度越高越快滿；滿了就輪到出手 |
| 跑道 | 上方全員頭像一起跑的畫面；起點 0、終點 100 |
| 出手順序（預測列，是否顯示待決） | 接下來 N 次出手的先後預測；你之後的格假設你出普攻。跑道已定：每個單位一個頭像，不限格數（17:44） |
| 手 | 你的一次出手 |
| 拍／息 | 戰鬥內固定時間單位，1 拍＝10 刻；畫面暫稱息；**刻不上畫面** |
| 後搖 | 條在 0 以下要多走的量 D＝−b（重招 W−100；失衡 50；撤退失敗 20）；剩餘 N 息＝D÷(10×速度)；輕行動沒有後搖，只是少等 |
| 輕招／平招／重招 | 出手後等待量：輕 60–90、平 100、重 115–140（普攻＝100） |
| 輕行動（防禦、道具、待機） | 不掛檔名；hover「出手後等得比較短」 |
| 先於你／後於你 | 敵人的重擊落在你下一次出手之前／之後 |
| 意圖 | 8 種：攻擊、重擊、流血、下毒、吸血、侵蝕、蓄力、防禦；**狀態不是意圖** |
| 狀態 | 失衡、狂怒、破甲、流血、中毒、後搖 |
| 紅霧妖 | 舊稱血霧妖（【待本地化確認】）；意圖「侵蝕」 |

## 5. 輕重各行動歸檔（給技能說明）

- 輕招：擒拿、盾擊、遊身、鴉影。重招：震地、內勁、破陣、連珠、奪命、重劈、崩岩擊。平招：普攻、突刺、橫斬、掃腿、瞄準。
- 防禦、道具、待機是輕行動，不掛招名。撤退失敗不掛檔。敵人不分輕重。
