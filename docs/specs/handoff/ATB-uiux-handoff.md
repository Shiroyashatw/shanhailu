# ATB 先交件：給 UIUX（跑道、意圖小標、狀態記號）

來源：`specs/SPEC-ATB.md` v0.1.3（§8、§9、§10；18:04 版）｜數值設計師｜2026-11-28（台北時間 UTC+8）。數字是規則，字串是暫定【待本地化】。草稿白底灰框黑字，狀態不靠顏色。

## 1. 跑道（每單位一個頭像）

- 顯示位置 `x = clamp(b, −50, 100)`（v0.1.3）：**0＝起跑線、100＝出手線**，**−50…0＝後搖區**；`b < −50` 釘在 −50 並加「«」（見 §7 逐題答覆）。到出手線＝輪到出手。你＝金色，敵人＝字符 `g`。
- **等待式**：輪到你時所有頭像停住；你選完指令，頭像才繼續跑，直到你再次到終點。
- **出手後的位置（後退量）**：頭像回到 `100 − W`。
  - 普攻、平招（W=100）→ 回起點。
  - 輕行動與輕招（W 60–90）→ 起跑線右側 `100−W`：待機 40、道具 30、防禦 20、遊身與鴉影 30、擒拿 20、盾擊 10。
  - 重招（W 115–140）→ 後搖區 `100−W`（−15…−40）；後搖區的頭像照常往右跑，過了起跑線才算還清。
- **起始位置**：

| 情境 | 你 | 敵人 |
| --- | --- | --- |
| 一般 | 終點 | 起點到 40％之間（隨機） |
| 先制（長兵） | 同一般；第 1 手出手後只回到 25％ | 同一般 |
| 伏擊 | 終點 | `b=−100`，畫面釘 −50 加「«」，直到真實 `b ≥ −50` |
| 遇伏 | 起點 | 終點，先各出手一次 |
| 失衡／打斷 | — | `b=−50`（後搖區最左，不加「«」），再走 50 到起跑線 |
| 撤退失敗 | `b=−20`（後搖區） | 不動 |

- 速度、疲累、負重改變時，頭像移動速度與位置**立刻重算**；動畫由你定。
- 同刻到終點：**你先，其次速度高者，再其次敵人編號小者**。

### 1.1 頭像數量、縮小、重疊（**已定 17:44**，mumi 選甲）

- **每個單位一個頭像，不限格數**（你＋所有存活敵人，之後同伴也算）。沒有「最多幾個」的上限；「8」只是縮小起點，不是上限。平常場上敵人 ≤2，所以通常 3 個頭像。
- **縮小**：頭像數 `N ≤ 8` 標準尺寸；`N > 8` 縮小為 `max(0.5, 8÷N)` 倍；`N > 16` 不再縮小，只重疊。像素與縮小後的辨認方式你定；縮小時狀態記號可合併成角標。
- **誰蓋在上面**：①位置越靠終點越上層；②顯示位置相同（`b ≤ −50` 的都釘在 −50，視為同位置）照平手規則：你 → 速度高者 → 敵人編號小者，先出手的在上；③輪到出手的頭像（在終點）永遠最上層。
- 頭像數量與下面的預測列、8 次推演**無關**：8 次推演只給預測、預演和決策器。
- 重疊時怎麼辨認、怎麼選目標：見下面 1.2（你的答覆，已寫進規格 §8.0.2）。

### 1.2 辨認與選目標（**已答、已定 17:48**，你的答覆＋數值設計師裁定）

1. **跑道頭像不能點選來選目標。** 選目標只有：點舞台上敵人的狀態牌；或按鍵 `Tab`／方向鍵輪換、`1`–`9` 直選、`Esc` 取消；手把用肩鍵輪換。規則層仍走 `setTarget(idx)`。
2. **編號小章**：每個敵方單位一個（`1`、`2`、`3`…），狀態牌與跑道頭像同號；滑鼠移到任一邊或焦點在任一邊，**另一邊同時高亮**；被高亮的跑道頭像**暫時浮到最上層**。你（玩家）不編號，用外框；同伴編號之後由 SPEC-COMP 定。
3. **玩家外框**：外圍加一圈不會被遮住的外框，**不影響位置、不影響疊層規則**。
4. **編號規則（裁定）**：開場固定，`no = idx + 1`，之後不重排；增援、召喚接下一個沒用過的號碼；死亡或逃走後號碼不回收、不補位；`1`–`9` 可直選，**`10` 號以上只能輪換選**；輪換跳過已死亡單位，依號碼由小到大循環。
5. 決策器與推演資料（`order`、`foes`）也帶 `no`，所以預測列若要顯示號碼，直接用它。

## 2. 預測列「出手順序」（**是否顯示仍待決**，SPEC-ATB Q-ATB-11；建議不顯示。跑道本身已定，不受影響）

- 內部一律推演接下來**至少 8 次出手（且延伸到你的下一次出現）**，只供預測、預演、決策器，與頭像數量無關；若顯示，顯示 4 或 8 格由你定（待決）。第 1 格＝現在輪到的人（你，t=0）。
- **確定**（實線框）：你的下一次出手之前，只有敵人出手的格子。**預估**（虛線＋淡字）：你第 2 次出現之後所有格；你的格假設「普攻」。
- 敵人只有第一次出現的格顯示意圖小標；之後顯示「？」。
- **預演**：滑過（或聚焦）指令列的某個行動，預測列暫時改為「若選這招」；移開恢復。
- 若只有跑道、沒有預測列（Q-ATB-11 採甲）：唯一的預測資訊是敵人頭像上的「先於你／後於你」。
- 重算時機：你出手後、敵人出手後、敵人死亡、意圖改變、失衡／打斷、疲累跨 80、撤退失敗。

## 4. 先後記號與狀態記號（**不是意圖**）

- 先後（敵人頭像角落）：**先於你**＝重擊會在你下一次出手前落下；**後於你**＝你還有時間打斷或防禦。
- 狀態（頭像角落，疊多個時你定優先序）：**失衡**、**狂怒**（首領，一次性，到戰鬥結束）、**破甲 N**、**流血 N／中毒 N**（剩 N 息）、**後搖 N**。**狂怒是狀態，不占意圖欄。**
- 「息」是玩家畫面上「拍」的暫定字串（待本地化）；**「刻」不得出現在畫面**。
