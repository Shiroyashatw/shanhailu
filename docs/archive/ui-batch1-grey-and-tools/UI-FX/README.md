## 結論

- 清單 **57 條**（`FX-LIST.md`／`FX-LIST.csv` v0.3）：●第一批・有草稿圖 29 條、○第一批・共用元件 11 條、△後批 17 條。較 v0.1 新增 T15 日結摘要卡、X12 戰鬥閃光預算。
- 草稿 **8 張**：6 張場景分鏡（FX-01–06，三欄 1280×720 ＋ 下方關鍵幀與時間軸圖板）＋2 張系統規格頁（FX-07 數字跳出規則、FX-08 設定與無障礙）。
- 核心做法：**邏輯按下即結算，演出只是回放，不鎖輸入**；小階回饋克制（≤1000ms、無粒子）；數字跳出同錨 ≤3、全畫面 ≤6、400ms 合併；全屏閃光每秒 ≤3 次、間隔 ≥400ms（含戰鬥既有 cflash，未驗，待開發實測；超過則收；本批新演出為 0 次全屏閃白）；每個效果都有「減少動態」替代；日誌永遠是保底，且新行在演出結算幀才顯示（避免劇透夜警與途中事件，跳過則立即顯示）。
- 時間流逝演出已對上正式四時段：清晨 05:00–08:00、白天 08:00–17:00、黃昏 17:00–20:00、黑夜 20:00–05:00；右欄時段條段寬 3／9／3／9，鐘點為次級。

## 音效風格方向（待 ART-FX／音效定稿）

方向已定：**克制，近人聲與器物，少合成音**。本批仍只留事件名與感覺描述，不做音效檔、不定音量與混音。各事件的「感覺」應對齊此方向（例：金屬短擊、柴火低鳴、腳步循環、單音上揚），避免電子合成或華麗樂句。清單見 X11 與各列「音效預留」欄。
