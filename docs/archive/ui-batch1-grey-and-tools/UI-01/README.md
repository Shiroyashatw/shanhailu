## 1. 流程

```
標題頁（山海錄＋一張「平民」卡；本包不另出標題頁圖，01 以身分卡承接）
    → 點「平民」卡，中欄換成「取名」頁（SHL-UI01-01）
        姓、名兩欄，預設「沈衡」，可「隨機」或直接「確定」
        可「返回標題」退回標題頁（不寫入名字）
        輸入時右欄即時預覽「沈衡・平民」
    → 確定後寫入 S.name = {sur, given}，在灰窯鎮醒來
    → 名字出現在：右欄頭像旁、中欄日誌列、日誌 overlay、NPC 稱呼（SHL-UI01-02）
      NPC 在畫面改以職稱顯示；稱玩家「沈客官」（MVP 姓＋客官）
    → 生命歸零：中欄墓誌銘，存檔刪除；左右欄仍在、名字仍在（SHL-UI01-03）
        副標註「平民出身・享年…」；一鍵重開回標題頁
        依終局換成「有墓／獸化／世上無墳」三種寫法（SHL-UI01-04）
```

舊存檔沒有姓名結構時，讀成「沈衡」（living-world v0.2 §6）。不做性別選擇。稱呼不分性別。

**01 狀態切換（不另開圖）**

- 合法（本圖主狀態）：確定可按；右欄即時預覽「沈衡・平民」。
- 不符：確定熄滅，規則句換成示範的兩條（非中文／字數不合）。不再做「不得與命名 NPC 同名」檢查。
- 隨機：從開局整池 60 組抽一組，不依身分、性別或風格篩選。示例取自 `name-pool-v0.1`：郝朔、祁禾、柯磐、汪季航、包拴。預設「沈衡」不在池內。
- 返回標題：退回標題頁（山海錄＋一張平民卡），不寫入名字。

**02 不是單一實機幀**。為了一次核對名字的去處，把日誌面板、懸賞令預留條、NPC 對白畫在同一中欄。實機是分開會話與日誌 overlay。醒來句寫身分：`沈衡（平民）在灰窯鎮醒來。` 對話 NPC 以職稱「灰窯說書人」顯示（設計碼：鐵嘴）。玩家被叫「沈客官」是 MVP 稱呼（姓＋客官），與常人世稱「路人」不是同一欄。

**懸賞令**：本批不做完整通緝令／告示榜畫面，只預留名字欄，文案例「緝拿 沈衡，賞銀 250 兩，死活不論」。告示榜完整版歸 UI-02。判決書、獵令同樣只預留名字，不畫。

## 3. 設計取捨（對照同類遊戲）

- **Darkest Dungeon**（莊園墓園：名字＋死因，一塊碑記一生）：墓誌銘留在中欄、一次一碑，不做成墓園列表。此生永久死亡，沒有園區可逛。
- **Rogue Legacy**（祖先畫像＋墓誌、以子嗣再開）：只借「死後留下一塊寫了名字的碑」。重開是「一鍵重開」回到標題頁，不是家系繼承。義莊遺物屬「之後」，本包只標預留。
- **Wildermyth**（把名字織進散文悼詞）：12.9 規定的是結構化欄位（所屬、善惡段、死因、終局），不是一篇生成故事。因此保留 v0.3 已有的一句引言，欄位本身用標籤列，方便本地化鎖字數。

取名頁做成**中欄專頁**（接在標題頁的一張平民卡之後），不用蓋住整屏的系統彈窗，也不新開解析度。標題頁本身只放這一張卡，不再提供多出身選單。姓、名分開，是因為 MVP 稱呼要用姓（「沈客官」）。

世上無墳的視覺差收成兩種框（已拍板）：**雙線石碑＋「之墓」＝有墓**；**單線記錄件＋只寫全名、不寫「之墓」＝世上無墳**。記錄仍給玩家看，但不進城鎮。

階段名與墓誌銘分詞（已拍板）：三階為「結契、初融、終融」；路線總稱與墓誌銘終局仍用「怪化」（或「遭獵」），不把「終融」寫上墓誌銘。

左右欄對齊目前實機三欄殼（main @ de91435231ed），本包不重做主介面。依 16:07 指示與已拍板 UI-DROP：左欄不畫「地面」10 格、不畫小地圖（實機小地圖位置早已改為勢力清單）；空出的位置標「之後：同伴」，不在本包設計同伴介面。新增畫面（取名、日誌條目、對白、墓誌銘內文）字級 ≥16px，新增按鈕熱區 ≥44。系統鈕等既有主介面元件維持實機尺寸。

**身分／所屬／平民出身**：開局身分是「平民」（數值沿用舊流民：素質全 10、銀 60 兩、鏽刃＋布袍、無熟練度）。入派後身分隨所屬改變。HUD／日誌寫「身分：平民」（本包右欄作「沈衡・平民」）。墓誌銘副標固定註「平民出身・享年…」；最後身分若已入派，由所屬欄呈現。

## 4. 文字字數上限（給本地化編輯）

已拍板的硬規則：姓 1–2 字、名 1–2 字，合計 2–4 個中文字；只收 CJK 統一漢字；不收空白、符號、英數。另有基本禁字表（v0.1 已列三、七、九、滿、衡；池內無名含這些字）。NPC 改為生成後，不再做「不得與命名 NPC 同名」檢查。

**姓名池**：開局從整池 60 組（姓＋名）抽一組，不依身分、性別或風格篩選。舊六種風格分組只作 NPC 命名氣味，不是玩家出身。01 圖示例取自 `name-pool-v0.1`：郝朔、祁禾、柯磐、汪季航、包拴。預設「沈衡」不在池內。

以下是畫面排版用的建議上限（按最長 4 字全名、2 字姓估），請 LOC 在撰稿時鎖住，避免溢出：

| 位置 | 格式 | 建議上限 |
| --- | --- | --- |
| 姓／名欄 | 各 1–2 字 | 硬限制 |
| 全名預覽、右欄第一行 | `{姓}{名}` | 2–4 字 |
| 右欄第二行 | `{身分}・{年齡}歲` | 開局為「平民」（2 字）；入派後隨所屬；整行建議 ≤10 字 |
| 日誌醒來 | `{全名}（{身分}）在{地名}醒來。` | 全句建議 ≤28 字（不含後接事件句）；開局寫「（平民）」 |
| 日誌死亡 | `{全名}死於{地名}：{死因}` | 全句建議 ≤32 字；死因建議 ≤12 字 |
| NPC 稱呼（MVP） | `{姓}客官` | 3–4 字 |
| NPC 稱呼（v0.5） | `{姓}大俠`；鴉衛叫全名 | 大俠 3–4 字；全名 2–4 字 |
| 懸賞令預留 | `緝拿 {全名}，賞銀 {n} 兩，死活不論` | 固定框詞 + 全名 4 字；數字另計 |
| 墓題（有墓） | `{全名}之墓` | 最多 6 字，單行不折 |
| 墓題（世上無墳） | 不寫「之墓」；標題「墓誌銘」，其下寫全名 | 全名 2–4 字 |
| 所屬 | 派名；或「曾屬{派名}」；回頭加「回頭」；臥底寫兩個身分 | 建議 ≤10 字；臥底建議 ≤16 字 |
| 善惡段名 | 義名／良善／常人／惡名／兇名 | 2 字（硬限制） |
| 善惡世人稱呼 | 大俠／好人／路人／惡徒／兇煞（接在「・世稱」之後） | ≤3 字。常人世稱是「路人」，不要寫成「客官」（客官只用於 NPC 稱呼玩家） |
| 善惡顯示格式 | `{段名}・世稱{稱呼}`，例「惡名・世稱惡徒」 | 段名 16/700 為主、稱呼 14/400 灰黑為次；15:19 定稿用字 |
| 墓誌副標 | `平民出身・享年 {n}・卒於…` | 「平民出身」四字固定註記，即使後來入派也不刪 |
| 終局用語 | 伏法、獻祭、沉江、契滿、換盡、成傀、蠱發、獸化、霧散、餵怪、怪化、遭獵 | 2 字（已定名，不改條文）。階段名「終融」不寫入此欄 |
| 墓誌引言 | v0.3 依生平選一句 | 建議 ≤22 字（含引號外的正文） |
| 不符提示 | 兩條固定句（見 01 圖：非中文、字數不合） | 各 ≤22 字 |

地名請一併控制在 4 字左右（現況最長如「官道驛站」「酉神裂口」），否則日誌與墓誌副標會超寬。
