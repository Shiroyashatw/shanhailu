## 一、核心願景與玩家體驗

- **一句話定位**：活在中式暗黑山海世界的硬派沙盒人生——跑商、冒險、賞金、勢力與旅途生存。
- **世界觀與美術路線**：中式暗黑、山海經志怪、灰燼石碑氛圍，採像素美術路線（15 分鐘 MVP 先做灰盒驗證玩法循環）。
- **市場切入點**：對標 *Stoneshard*、*Battle Brothers*、*Vagrus*、*Roadwarden* 的旅途生存與跑商決策，切入中式暗黑山海像素沙盒空白，去掉過度微操與繁瑣詞綴打造。
- **核心玩法循環**：
  1. **城鎮整裝**：決定這趟帶幾格特產、幾份乾糧、穿輕裝還是重甲、是否換更大的背包、接不接賞金。
  2. **商路跋涉**：在官道（穩、耗時）與捷徑（快、險）間抉擇；負重直接影響移動耗時、飽食／疲累消耗與遇險次數。
  3. **地城與回合戰鬥**：靠敵方意圖預告做戰術應對；贏了帶走裝備與殘卷，打不贏可選擇**棄貨撤退**保命。
  4. **滾大資本與熟練度**：進城銷貨、買更大背包或更好裝備、透過行為自然成長熟練度，挑戰更深地城與更遠商路。
  5. **永久死亡**：一失足即結束此生，留下簡短生平墓誌銘。

## 二、固定三欄單屏 UI 架構（桌面 1280×720 單屏）

全遊戲維持固定左、中、右三欄，不靠層層彈窗遮蔽資訊：

| 欄位 | 寬度配比（建議） | 常駐內容 | 設計原則 |
| --- | --- | --- | --- |
| **左欄：身型與物資** | 約 28%–30% | 上半：POE 式人形身型裝備（10 部位＋1 獨立背包槽）；下半：動態背包格與總負重／速度條 | 紙娃娃固定不縮水；背包依容量換行或區內捲動 |
| **中欄：世界主舞台** | 約 44%–46% | 依狀態無縫切換 4 種情境：地圖移動、城鎮買賣、旅途事件、RPG 回合戰鬥 | 單一焦點舞台，不跳轉雜亂全屏彈窗 |
| **右欄：生存與成長** | 約 26% | 生命、飽食度、疲累度、負面狀態、行為熟練度清單、已習技能 | 即時反映負重與旅途消耗，方便戰前判斷 |

### 中欄 4 種情境切換
1. **地圖移動**：節點式商路與地城路線，出發前明示耗時、飽食與疲累消耗預估、遇險機率；疲累過高時可選擇野外紮營（含夜間警戒風險）。
2. **城鎮買賣**：市集特產行情（跨城價差）、背包行、裝備商、客棧休整、賞金板，並預留勢力與酒館入口。
3. **旅途事件**：2–3 個低字數高後果選項（劫匪、荒廟、迷霧、異獸、古碑），清楚標示熟練度檢定或資源代價，談判破裂可直接切入戰鬥。
4. **RPG 回合戰鬥**：中欄原地展開，顯示敵方意圖預告、行動條／速度順序、技能列與「棄貨撤退」按鈕。

## 三、核心系統規格

### 3.1 裝備與詞綴規則（大簡化定案）
- **POE 式人形身型部位（10 裝備部位＋1 獨立背包槽）**：
  - 武器與副手（2）：主手、副手（雙手武器佔用主副手；副手可配盾牌／法器／副刃）。
  - 防具（4）：頭盔、胸甲、手套、靴子（防具自重計入全身負重）。
  - 飾品（4）：護身符、左戒、右戒、腰帶。
  - 行囊（1）：獨立「背包槽」，專門穿脫背包商品。
- **稀有度分級**：
  - **白（凡品）**：0 條詞綴，僅基底數值。
  - **藍（良品）**：1–2 條詞綴。
  - **稀有（珍品）**：2–3 條詞綴。
  - **傳奇（遺物／神兵）**：2–3 條詞綴＋1 條專屬機制詞條。
- **詞綴生成規則**：
  - **不分前後綴**，一件裝備**最多 3 條詞綴**。
  - **取消詞綴等級（T 階）**，直接於該詞綴的數值區間內隨機骰出。
- **明確不做**：沒有打造通貨、沒有天賦樹、沒有昇華。裝備更新完全靠地城掉寶、賞金與城鎮買賣。

### 3.2 背包商品化、負重與行動速度、馬車擴充定位
- **背包商品化**：背包是可買賣／更換的商品，裝備於獨立背包槽。
  - 初始：**粗布小包（6 格）**。
  - 後續城鎮可購：行旅皮囊（10–12 格）、商旅背簍（16 格）、精工大囊（20–24 格）。
- **負重與行動速度公式方向**（參數交由數值設計師定案）：
  - `有效行動速度 = 基礎速度 × (1 - 負重懲罰係數)`
  - 總負重 = 身上裝備自重 ＋ 背包空包自重 ＋ 背包內貨物／補給重量。
  - 三段負重區間方向：
    - **輕裝（≤40%）**：移動耗時正常、戰鬥先手與撤退成功率最佳。
    - **常態重負（41%–75%）**：路程耗時增加、飽食／疲累消耗略升、戰鬥速度下降。
    - **超載（76%–100%）**：大幅拖慢腳程、遇險次數上升、戰鬥嚴重減速，幾乎必須棄貨才能撤退。
- **馬車系統後續擴充定位（架構預留，非 MVP 實作）**：
  - MVP 15 分鐘試玩只實作「背包購買更換＋負重影響速度」。
  - 資料結構與 UI 預留「載具／馬車槽」：完整版可於城鎮雇用或購買馬車，提供大型獨立貨倉、分擔人力負重，但限走官道、無法帶入地城，並延伸車夫薪資與劫車事件。

### 3.3 生存系統、行為熟練度與技能取得
- **生存雙指標**：
  - **飽食度**：隨移動與時間消耗；過低導致回復停滯與戰力衰減，需吃乾糧或進客棧補充。
  - **疲累度**：隨趕路、負重與戰鬥累積；過高降低命中、速度與事件成功率，需客棧休整或野外紮營恢復。
- **無等級系統，改行為熟練度**：取消 XP 與角色等級，依實際行為（武器、防禦、議價、行腳、探索）自然提升熟練度，微幅提升效率並作為進階技能門檻。
- **技能取得**：不靠升級點數；MVP 由地城殘卷取得，完整版擴充至城鎮勢力（商幫、鎮妖司、古宗門）依聲望學習。

### 3.4 RPG 回合戰鬥與永久死亡／雙模式存檔架構
- **敵方意圖預告**：每回合明示敵人下一動（重擊、流血、蓄力、防禦），強化戰術應對。
- **棄貨撤退**：戰況不利時可勾選拋棄部分背包貨物，直接換取撤退成功率大幅提升。
- **永久死亡與雙模式預留**：預設為純永久死亡（死亡即刪檔並產出「生平墓誌銘」）；底層存檔架構預留「城鎮檢查點快照」開關，正式版可依玩家需求開放雙模式。

### 3.5 世界觀切片（MVP 與後續藍圖）
- **15 分鐘 MVP 切片（名稱暫定，後續由本地化潤飾）**：
  - **2 座城鎮**：灰窯鎮（產粗鹽／生鐵／粗布小包）↔ 渡陰關（產山藥／燻皮／行旅皮囊、高價收鹽鐵、設賞金板）。
  - **商路節點**：1 條安全官道（3 節點）＋1 條山嶺捷徑（2 節點，高遇險），共 4–5 個事件節點。
  - **2 個地城**：亂葬古窯（低危，掉白／藍裝與基礎殘卷）、沉淵祭窟（中高危，掉稀有／傳奇試做裝與高價遺物）。
  - **基礎賞金**：商路討伐與地城清理目標。
- **完整版／V2 藍圖**：多勢力聲望與門派習技、酒館招募護衛／車夫、馬車商隊、鐵匠修理與特製訂單、大世界多區域山海地貌。

## 四、15 分鐘試玩版（MVP）範圍切分

| 系統模組 | 階段 | 範圍內容 |
| --- | --- | --- |
| 三欄單屏灰盒框架 | **MVP 必做** | 1280×720 左中右固定三欄、中欄 4 情境無縫切換 |
| POE 式身型裝備與簡化詞綴 | **MVP 必做** | 10 人形部位＋1 背包槽、白／藍／稀有／傳奇、最多 3 條區間直骰詞綴 |
| 背包商品化與負重速度 | **MVP 必做** | 6 格小包起步、城鎮買更大背包、負重影響移動耗時與戰鬥速度 |
| 生存、熟練度與技能 | **MVP 必做** | 飽食與疲累、行為熟練度自然成長、地城殘卷習技能 |
| 回合戰鬥與棄貨撤退 | **MVP 必做** | 敵方意圖預告、速度順序、棄貨撤退檢定 |
| 永久死亡與世界切片 | **MVP 必做** | 純永久死亡＋墓誌銘、2 城鎮、1 官道＋1 捷徑、2 地城、基礎賞金 |
| 城鎮檢查點雙模式 | **架構預留** | 底層存檔結構預留開關，MVP 介面只跑純永久死亡 |
| 馬車載具系統 | **架構預留** | 資料結構與 UI 預留載具槽，完整版開放雇用／購買馬車 |
| 勢力聲望／酒館招人／鐵匠 | **V1／V2 延後** | 勢力學技能、招募護衛車夫、鐵匠修理與客製 |
| 正式像素美術與大世界擴充 | **灰盒驗過後** | 15 分鐘循環好玩才投入美術與內容擴充 |
