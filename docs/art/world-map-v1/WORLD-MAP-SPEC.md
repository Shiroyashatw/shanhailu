## 2. 大陸 Z0 定稿的地理（12:43 回饋：要自然，不要格子）
- **海岸**：曲折，有半島、海灣；外海寬 16–32 原生 px（雜訊），之外是**大荒**（近黑虛空＋碎石點），四周都看得到。
- **島**：18 座大小不一（3–16 px），西側群島最密（奇肱國最大），南方三身國次之。
- **山脈**：西北崑崙丘（紅裂三峰、血霧）接北山冰脈（含凍湖＝寒淵），東山一條南北長脊＋灰色高台（扶桑坡）；山脈相扣，不再四山各守一邊。
- **地貌**：瘴澤盆地（西）、灰窯原（西山東麓平原，夾在瘴澤與中山外環之間）、中山火口高台（暗）、南山火山群（三錐）＋西南沙漠、東山森林與峽谷、北方冰原。
- **水系**：黑水自瘴澤東流，經灰窯原南、中山南，入**海內**（東南深入的內海灣，頭部＝黑水渡）；北支自北山南下、東支自東山峽谷入內海；灰窯原北支南下穿官道（＝官道河橋）。
- **宇宙觀只保留大方向**：中山居中、四山大致在四方、海內＝內海、海外＝外島、大荒＝外圈；不對齊、區塊大小不一。
- **不出現**：西方翼龍、任何西洋奇幻母題（v0.1 外圈翼龍已整片重畫掉）；地形圖上沒有生物、沒有字。

## 3. 區塊與勢力地盤（資料驅動、沿地形）
- **大區塊**：`src/geo.py` 以各區人工種子點做**地形測地 Voronoi**（8 鄰 Dijkstra）。成本＝`1 + 22×坡度^1.3 + 30×河道`，水域不可走 → 邊界自然落在山脊、崖線與河上，沒有多邊形格子。輸出 `data/regions_398x280.png`（值＝區號+1）。
- **灰窯原 5 區**（依清單／藍圖 v0.3）：官道東西向為軸（灰窯鎮東端 → 驛站 → 河橋 → 渡陰關 → 破曉營西端）；野徑藥林＝官道南、岔口西；窯礦坡＝中南→西南；腐沼塚地＝灰窯鎮東南→南；獸徑裂口＝最西南（酉神裂口）。在灰窯原區內再做一次測地 Voronoi → `data/huiyao_zones_398x280.png`。
- **領土型勢力**（Z0 只畫這 6 個）：白虎、朱雀、玄武、青龍、炎祝部、北海冰部。做法：在各自所屬山區內，以清單上的點當種子做測地 Voronoi。種子是該勢力控制的點；其他勢力、「無」、「爭：」的點都當空白種子；治所（大城／鎮／關口）有距離優勢。之後清碎片（<30px）、做多數決平滑。依藍圖「官道帶屬白虎軍」，官道兩側 ±7px 整帶併入白虎。輸出 `data/territory_398x280.png`。
- 網絡型、據點型勢力不畫地盤；Z0 只放**總壇印**（9px 菱形印，勢力色）。與城同點的總壇（黑水盟、千機閣、換骨樓）印掛在城的右上。

- **定位法**（csv 沒有座標，所以由本規則推出，可重算）：
  1. 人工：Z0 可見點與區塊骨架點共 89 個，寫在 `geo.py` 的 `MAN`。
  2. 自動「參照點＋方向詞」：方位文字裡出現已定位的地名，就以該地為基準；方向（東／西南…）配距離詞（內 0.7、旁／口／岸 1.8、外／側／之間 2.6、其餘 3.2 px）；「A 與 B 之間」取中點。
  3. 自動「區塊範圍＋方向詞」：文字沒有參照地名時，取區塊外接框中心，往方向詞推 55%（「緣／端／角／最」推 85%）。
  4. 落點吸附到所屬區塊遮罩，點距 ≥1.2 px（暗路點 0.8）。
  5. 鎮內 32 點與所屬城鎮同座標，畫在城鎮平面上，不上世界圖。
- 統計：人工 89、參照點 215、區塊範圍 22、鎮內 32。
