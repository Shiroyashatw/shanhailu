- 城況條「出城路險 低／高」（02、03）是**城鎮狀態另一個元件**，不是右欄險列，**不受 18:18 規則影響**，保持原樣。

- 景內烤進像素的實機既有字（地名 11px、受創標 14px）不是 DOM 文字，沿用實機，未改。
