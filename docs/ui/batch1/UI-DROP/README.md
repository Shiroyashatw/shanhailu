## 用詞

hover 一律句尾不加句號。「身分」不用「出身」。灰髯狼、鎮衙、紅霧。

| 位置 | 字 |
|---|---|
| 委託物品 hover | 這是委託物品，不能丟棄 |
| **制式裝備 hover** | **這是制式裝備，不能丟棄**（【暫定，待本地化】只寫在圖例與本檔，畫面上沒有） |
| 丟棄 hover | 把東西拖出左欄並放開，物品會立即消失且無法撿回 |
| 負重 hover | 目前攜帶的重量與可承受上限，過重會拖慢腳程並加重疲累 |
| 腳程 hover | 趕路速度受負重、裝備與疲累影響 |
| 裝備丟棄說明（07） | 裝備也直接丟／不用先卸下，放開就消失，無法撿回 |
| 戰利品面板 | 狩獵剝皮／銀兩 +6／點取・可疊入／放不下／1 件將遺失／按「繼續」時，沒拿的就丟掉，無法撿回／繼續 |
| 日誌 | 丟棄了 止血草 ×4（裝備寫「丟棄了 鐵盔」，不寫 ×N）／行囊滿，缺 1 格（沒耗時間、沒耗疲勞）／放不下的 1 件，按「繼續」時會遺失 |
| 標記 | 禁（不能丟）、丟（戒備態）、拖（拖曳中）、示意、【佔位】 |
