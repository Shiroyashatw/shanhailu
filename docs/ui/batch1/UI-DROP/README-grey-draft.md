## 欄位規則（mumi 17:23）

每一側欄只固定放一種東西，玩家不必記「這次在哪一邊」。

**左欄＝東西**：人形裝備、容器頁籤、行囊格、負重與腳程。裝備與負重都跟物品有關，故留在左欄。勢力清單已移到右欄「勢力」頁。不再畫「之後：同伴」佔位。

**右欄＝同伴及其他非東西**：上方釘選，下方用頁籤。

釘選（不收進頁籤）：頭像、姓名、身分、地點、銀、日、時段條（段寬 3／9／3／9，時段名寫在條上側，不塞進窄段）、命／食／疲、危險警示（有才出現）、以及**當前目標**。建議把進行中的短期目標釘在頁籤上方，理由與危險相同：這是此刻要盯的事，不該翻頁才看得到。實機已有 `trackedQuest()`。完整委託、傳聞列表放在「記事」。

右欄頁籤：角色／同伴／勢力／記事。同伴頁只畫虛線佔位，內容交 UI-COMP。底列系統鈕收成日誌／說明／選單（記事、人物併入頁籤）。

## 容器頁籤與丟棄區

實機同時只能裝備一只背包（買新包會把舊包收進行囊）。本包頁籤是**同一只包的分頁**，不是同時擁有多只包：

- **隨身**：目前裝備背包的第 1 頁（最多 20 格，5×4，每格 44×44，不捲動）。
- **第 2 頁**：只在容量大於 20 時出現（精工大囊 24＝20+4）。
- **推車**：架構預留、本版鎖定，提示為不可用。放開＝取消，不是丟棄。

拖到頁籤＝整疊移入該頁。頁籤是有效目標，**不是丟棄**。若該頁已滿且不能堆疊，視為無效目標，物品回原格，不丟棄。

**丟棄區＝左欄以外**（且不是可裝備部位、店內賣出欄等有效目標）。游標仍在左欄內時不會進入丟棄態。

## 互動（沿用並收緊）

- 按下後移動滿 **6px**（hypot）才出現幽靈、開始拖曳。一次拖走該格全部數量。
- 行囊內：籤寫「整理中」。有效非丟棄目標：可裝備部位＝穿上；店內賣出欄＝賣出；容器頁籤＝「放進××」。
- 離開左欄且不是有效目標：進入「放開即丟棄」（外框與紅籤）。沒有確認窗。
- 放開當幀結算，物品立即消失且無法撿回，不留在地上。日誌寫「丟棄了 {名} ×{n}」。幽靈 400ms 淡出只是回放。
- 四條取消途徑（不會丟、不寫日誌）：放回行囊任一格、無效目標上放開、Esc、滑鼠右鍵。後兩條為本包新增（實機目前沒有）。
- **委託物品不能丟**（mumi 17:27 已定）。嘗試拖曳不離開原格；格上標「禁」；hover：「這是委託物品，不能丟棄」。實機 `type:quest` 目前只有禁賣、未禁丟，本包按已定規則畫，實機待 DEV-DROP 補上。
- 行囊滿溢出物去向仍待數值，圖 05 只給暫定面板，不畫地面殘留。戰鬥棄物撤退仍寫「落在地面」，本包不改撤退流程。

回饋時序見 UI-DROP-04 圖例表。階層：小＜關鍵＜重大。

## 17:27 用詞

- 腳程寫「檔名 + 倍率」，例如「輕快 ×1.00」「平常 ×0.82」。檔名暫用輕快／平常／沉重／蹣跚，**切點待數值，本圖標暫定**。不把負重檔名（輕裝／常態重負／超載）直接拿來當腳程檔名。本圖 22/80 或 18/80 且倍率 1.00 → 輕快 ×1.00；48/80 且 0.82 → 平常 ×0.82。
- hover「趕路速度受負重、裝備與疲累影響」（句尾不加句號）。
- 狼寫「灰髯狼」。建築寫「鎮衙」。鎮衙說明（20 字，供之後建築 hover／圖例）：「每天補滿3張，過期撕榜，完成提高破曉聲望」。
- 危險四檔統一為低／中／高／極高（舊「中高」改「高」）。本包街景圖沒有出險，未畫警示列。
- 禁用詞見 `_shared/colour-fix-1727.md` 第 1 節；本包 src／html／畫面均未使用。

特殊名詞均附一句 hover，句尾不加句號：丟棄、負重、行囊滿、腳程。委託物品的說明寫在「不可丟棄」卡。
