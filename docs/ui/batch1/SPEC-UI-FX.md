## 時長與緩動 token

`fx-dur-xs` 120｜`-s` 200｜`-m` 360｜`-l` 600｜`-xl` 1000｜`-xxl` 1600。緩動 `out` cubic-bezier(.22,1,.36,1)｜`inout` (.65,0,.35,1)｜`pop` (.34,1.56,.64,1)（僅關鍵以上、減少動態時關）。階層：小＜關鍵＜重大；小階一律 ≤1000ms、無粒子。
