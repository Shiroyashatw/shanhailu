**a. DOM 自動檢查**（`_tools/render.js`，對每個 `#stage .tx` 文字節點；任何項不為 0 就 exit 1）：

| 項 | 判定 |
| --- | --- |
| 溢出 | `scrollWidth>clientWidth+1`，或 `scrollHeight>clientHeight+容差`（有指定高的框容差 1px；其餘 0.2em，因 CJK 字體內容區高於行高） |
| 被裁切 | 文字墨框超出自身 `overflow:hidden` 框 1px（橫向）／0.2em（縱向），或超出 1280×720 畫布 |
| 重疊 | 兩兩比對；橫向用文字墨寬，縱向用行盒（line box），交集 >0.5px 即算；若較下層的字被不透明塊蓋住（如展開簡報條蓋住平面圖字）不算 |
| 部分被蓋 | 每個字框取 7×3 取樣點，被不透明塊蓋住一部分（非全部）即算 |
| 行數 | `getClientRects` 數行；非多行段落必須 1 行（標籤／按鈕／數值），多行段落 ≤2 行 |
| 孤字 | 多行時最後一行只剩 ≤1 字 |
| 拆詞 | 逐字比對 y，數字／×／＋／−／小數點被拆到兩行 |
| 字級小於16 | `font-size<16px` 且不屬實機 HUD 例外；例外另列計數 |
| 徽章壓字／互壓 | 圖例編號圓章壓到可見文字、超出畫布、或彼此重疊 |
