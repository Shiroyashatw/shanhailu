## 5. 暫定項（interim）

- **危險四檔配色（17:45 已定）**：低 `--ink-2`＋◇、中 `--gold`＋△、高 `--red-text #e07066`＋!、極高 `--red-d` 底＋`--red` 邊框、字 `--ink`、!!。不使用 jade。路線危險程式目前只有三檔，第四檔切點待數值設計師。
- 收集／城鎮送貨的險級、長期委託的失敗罰則（標「未定」）
- 路線危險與地點固有險級是否合併算法
- 「地面」從 HUD 拿掉後，行囊滿時溢出物去向
- **側欄字級（17:45）**：左右欄所有遊戲 UI 文字均 ≥16px，已取消「實機 HUD 例外」。欄內放不下時改結構（縮寫圖示、兩列、或移進頁籤），不縮小字。
