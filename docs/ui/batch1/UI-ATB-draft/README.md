## 3. 跑道規格

位置 b：**0＝起跑線、100＝出手線**，往右跑。畫面顯示範圍 **−50…100**；−50…0 為**後搖區**（斜紋底＋標籤）。**只看位置，畫面上沒有數字。**

| 項目 | 規則 |
|---|---|
| 頭像 | 每單位一個；你＝圓角方框＋外圈（最上層疊加），敵人＝八角形＋2 位編號小章 |
| 出手 | 到 100 就出手，出手後回到 100−W 繼續跑 |
| 平招／普攻（W=100） | 回 0（起跑線上） |
| 輕招（W 60–90） | 回 10–40（起跑線右側，少等） |
| 重招（W 115–140） | 回 −15…−40（後搖區，後搖 N＝W−100） |
| 打斷／失衡 | 被打斷者退到 −50 |
| 撤退失敗 | 你退到 −20，其他頭像不動 |
| 超範圍 | 進度 ≤ −50 畫在最左端並加「«」；hover 說明 |
| 預覽（滑過指令） | 跑道上出現**落點影像**（淡虛線頭像）＋從出手線到落點的括弧箭頭＋全名階字（「重招・後搖」「輕招・少等」「回起點」）；不寫數字 |
| 下一位出手者 | 以 SPEC §8.1 模擬 `t=(100−b)/v` 決定，**不是看位置**；小籤反黑加字 |
| 同位置 | 你 → 速度高者 → 敵人編號小者；先出手者在上 |

### 3.1 意圖（8 種，跑道上小籤＝記號＋2 字）

| 代碼 | 標籤 | 記號 |
|---|---|---|
| atk | 攻擊 | 實心圓 |
| heavy | 重擊 | 實心三角（紅） |
| bleed | 流血 | 實心菱形 |
| poison | 下毒 | 實心方形 |
| drain | 吸血 | 半圓 |
| corrupt | 侵蝕 | 星 |
| charge | 蓄力 | 空心三角（紅） |
| guard | 防禦 | 空心方形 |

「狂怒」是**狀態**，不是意圖。記號形狀與字同時存在，不只靠顏色。

### 3.2 狀態記號（頭像右上角）
失衡「衡」、後搖「搖」、狂怒「怒」、破甲 N「破」、流血 N「血」、中毒 N「毒」。**優先序**：失衡＞後搖＞狂怒＞破甲＞流血＞中毒；最多顯示 2 個＋「…」，其餘在 hover。重擊小籤前綴「先」＝這一下會在你下一次出手前落下；「後」＝你還有時間（打斷或防禦）。

### 3.3 指令列上的輕重
輕招／平招／重招三階。**只有招式與技能掛階名**：輕＝按鈕右上角虛線框「輕」、重＝實心「重」，平招不標；防禦／道具／待機是**輕行動**，不掛階名。hover 說明行：重＝「出手後要等比較久」，輕＝「出手後等得比較短」。

## 4. 擁擠規則（mumi 17:44 → 甲案）

1. 每單位一個頭像，**不限數量**，不出現「+N」。
2. 縮放 = `max(0.5, 8/N)`（N>8）；N>16 停在 0.5，只重疊不再縮。N=11 → 0.73 倍：敵人 32→23px、你 40→29px；N=16 → 0.5 倍。
3. **x 永遠＝真實進度**，允許重疊，**絕不側移**。
4. 疊放：越靠出手線越上層；同位置依平手規則；**輪到出手者永遠最上**；被 hover／focus 的單位暫時提到最上（加外圈）。你的頭像有獨立框形與最上層外圈，永遠找得到。
5. 頭像內放編號數字（只有最上層、未被蓋住者畫字，被蓋住者不畫以免亂碼）；小籤只留記號，**只有下一位出手者與被 hover 者保留 2 字**。鄰近敵人間距 <66px 時同樣只留記號（ATB-09 一般開場）。
6. 同位置完全重疊（遇伏）：只畫上層，並在角落加「疊」記號（兩條折線，不用字）；hover 展開。
7. **hover 重疊處**：往下展開成名單（x 不變，每列 ≥44 高；列＝縮圖＋編號＋名稱＋意圖記號與字）。
8. 命中區：每個頭像有透明熱區 **≥44×44**（用展開區，不靠頭像本身大小）；框形與位置不因熱區而移動。

### 4.1 選目標（SPEC handoff v0.1.1 §1.1）
- **不能點跑道頭像選目標**。選目標用：敵人狀態卡、`Tab`／方向鍵循環、數字鍵 1–9 直接選、`Esc` 取消、手把肩鍵循環。
- **雙向連動**：hover／focus 卡片 → 對應頭像提到最上層＋外圈；hover 頭像 → 對應卡片加粗框。編號小章卡片與頭像共用（ATB-07 第 7 號）。
- 卡片熱區 ≥44；>3 隻敵人時改一排小卡（本稿 72×84）——**排法待 mumi**。

### 4.2 編號小章（數值設計師已確認）
- 編號**開戰時固定**（依敵人 idx 排序）。
- 中途加入者取**下一個沒用過的號**。
- **倒下或逃走的號不補**；可缺號（例：1、3、4；ATB-10）。
- **1–9 可直接選；10 號以上只能用 Tab／方向鍵**。
- 小章必須容得下 2 位數：寬＝8×位數＋8（1 位 16×16、「12」＝24×16），不溢出。

> **衝突**：現行 `ui.js:1043–1047`，數字鍵 1–9 已綁**戰鬥指令**（按第 N 個指令）。若再用 1–9 選目標會打架。選項：A) 選目標用 `Shift+數字`；B) 只留 Tab／方向鍵；C) 指令改 F1–F8。**待 mumi／數值設計師決定**，本稿 hint 行先寫「Tab／方向鍵換目標」。

## 5. 動態與時序（ATB-04／05／06）

| 段 | 時間 | 緩動／token | 說明 |
|---|---|---|---|
| T0 選指令 | — | — | 全部停止；滑過指令顯示落點影像與標籤（淡入 fx-dur-xs 120 out） |
| T1 確定 | 0–120 | fx-dur-xs ／ out | 落點影像變實線；你放大 1.1× |
| T2 滑回 | 120–720 | fx-dur-l 600 ／ inout | 你沿跑道滑到落點；淡虛線殘影＝軌跡；**其他頭像不動** |
| T3 落地開跑 | 720–840 | fx-dur-xs ／ out ＋ linear | 落地輕彈；之後全體等速（linear）往右跑 |
| 跑動 | 360–1000（到下一出手者所需，夾制） | linear | 超過 1000 就加速到 1000（暫定） |
| T4 快到線 | 最後 120 | out（減速進站） | 玩家在後搖區也在跑，要走過起跑線才開始追 |
| T5 到站 | 120 | out | 放大 1.1×、出手位反白；現行 e_act 300＋e_hit 190 不變；之後落點 600 inout |
| 打斷（A1／A2） | 0–360 ／ 360–480 | out ／ fx-dur-xs | 敵人沿跑道急退到 −50；「衡」標記彈出一次；小籤先淡出，到位後換新意圖 |
| 撤退失敗（B1／B2） | 0–360 ／ 360–480 | out | 你退到 −20；「搖」標記出現；其餘不動 |
| 條滿提示 | 0–200 | fx-dur-s | 外圈放大一次；**閃爍 ≤3 次／秒**（UI-FX X12） |

連續出手加速：同一串動畫第 2 次起所有時長 ×0.6；整串超過 2000 毫秒直接跳到結果；再按任一指令＝立即收尾（沿用現行規矩）。
**`?fx=0`／減少動態**：頭像直接跳位、不滑不彈不閃；記號、小籤、反白、細條照舊（ATB-06）。實機現行 `?fx=0` 只關閉戰鬥回放，且**沒有** reduced-motion CSS（未驗：只讀 css）；跑道動畫需新增。毫秒只寫在本 README 與分鏡圖例給開發，**不顯示給玩家**。
