## 6. 生成、消失、與活世界連動（藍圖 11.5.3–11.5.6）

- 由活世界數值觸發：匪勢、繁榮、治安、獸潮、季節、晝夜、天候、勢力活動。帶隨機：條件滿足後不是每次都必生（交數值定）。季節祭壇只按十二神祭日程，不隨機刷。
- 消失：時限到；被玩家或官府／破曉清除；被別的勢力佔走（佔走後視同消失或轉成暫時據點，規則交 SPEC-DYN）；季節更替（祭壇）。消失後空位冷卻（交數值定）。
- 地點 → 城況：流寇營推高匪勢與路險、壓低繁榮；遊方市集短期抬行情與繁榮；獸巢提高獸潮壓力；災後廢墟短期壓繁榮、抬治安需求。
- 城況 → 地點：治安低、匪勢高較易生流寇營與藏處；繁榮高較易生市集、較不易生流寇；獸潮過後較易生廢墟。幅度交數值，只求方向對。
- 勢力標記不改變第 7 節固定掌控。善惡、通緝、獵令的接口已寫方向，細則交 SPEC-DYN 並對齊 SPEC-02。
