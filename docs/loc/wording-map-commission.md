## 1. 地圖趕路（底列與圖上懸浮，同一套詞）

來源：`js/ui.js` `sceneMap`（底列 `vpill`、圖上 `tipbubble`），數值由 `js/game.js` `travelPreview()` / `speedMult()` / `loadBand()` 算出。

| 舊（實機現用） | 新（擬案） | 機制（給 LOC 與數值，不寫進玩家提示） | 懸浮說明（擬案；一句，不寫 UI 未讀的數字） |
| --- | --- | --- | --- |
| `時` + `N 小時` | **路程** N 小時 | `hours = max(1, ceil(基礎時數 / speedMult()))`。基礎時數為路線各邊 `e.h` 之和。 | 這次出發會耗掉的時間，依路線與目前腳程算出 |
| `食` + `−N` | **飽食** −N | `food = 4 * hours`，趕路時扣飽食。 | 趕路會消耗飽食，過低時生命不再回復 |
| `疲` + `+N` | **疲累** +N | `fat = round(3 * hours * 負重檔.fat * 腳力減免 * (1−減疲詞綴))`。 | 趕路會累積疲累，過高時命中與腳程都會變慢 |
| `險` + 低／中／高 | **危險** 低／中／高／極高（四檔） | 路線遇襲率：野徑 0.22 或 0.30（多段），官道 0.04；夜間 ×2、超載 ×1.4、獸潮 ×1.5 等，現行程式分低＜0.15／中＜0.35／高三檔；統一四檔後第四檔「極高」的切點【暫定】，待數值設計師。 | 這條路遇襲機會的高低，夜間、負重過高或走野徑時較易遇險 |
| `負` + `×M` | **腳程** 檔名 ×倍率，例：輕快 ×1.08（16:29 拍板；17:27 拍板格式） | 值仍是 `speedMult()`，用來除路程時數，不是重量本身。重量在左欄顯示為「目前／上限」。由負重檔位、速度詞綴與力竭（疲累過高）決定。 | 趕路速度受負重、裝備與疲累影響 |

補充：

- 底列「經 野徑岔口」沿用實機 `via`（多段路取第一站名；單段官道寫「官道」、野徑寫「野徑」）。
- 「前往」「此地」「進入此地」不改。
- **危險分級統一四檔：低／中／高／極高**（17:27 拍板，17:43 製作人確認已定）。地點舊稱「中高」改「高」。切點照 SPEC-TIME v0.5 §7.1b：路程門檻 0.15／0.35／0.60（半開區間）；委託單取路程級與地點級較高者；算法仍分開，不改機率與 0.85 封頂。現行程式的路線危險仍是三檔，實作時改四檔。彩色稿的色與圖示仍為【暫定】（見第 5 節）。

字數（擬）：標籤 ≤ 4 字（「腳程」為 2）；格內數值隨 brief／preview；懸浮說明單句，不超過兩行 16px。

## 2. 委託單（鎮衙）

來源：`js/ui.js` `tabBounty` / `sceneBuilding`，接榜 `js/game.js` `questAct`、`questTick`，生成 `QUEST_GEN`，地點險級 `WILDS`／`DUNGEONS`.risk。

| 舊（實機現用） | 新（擬案） | 說明 |
| --- | --- | --- |
| 扁卡標題 `灰髯狼 ×3・40兩` | **目標**列：`獵殺灰髯狼 ×3`（大字；做什麼＋數量） | 標題型 ≤8 字為原則。種類詞：獵殺／收購／送貨至。 |
| 副行地點＋期限混寫 | **地點**獨立一行 | 例：`枯骨獸徑・青霧藥林`、`帶回此地交付`、`送到渡陰關`。≤22 字。 |
| 報酬併在標題 | **報酬**塊：`報酬 40 兩`；送貨加 `・押金 10 兩` | 讀 `questReward` 與 `deposit`。token `--quest-reward`。 |
| 副行 `長期`／`剩 N 天`／`今日截止` | **時限**塊獨立 | `長期`、`剩 N 天`、`今日截止`（實機已有）。剩 ≤ 1 日為緊急，紅字。token `--quest-due`／`--quest-due-urgent`。 |
| （無） | **風險**塊：險級＋一句失敗後果 | 見下表。 |
| `揭榜`／進度 `0/3` | 仍用 **揭榜** 或 **進度 a/b**，熱區 44 | 風險寫在單上，不另開確認窗。 |
| 腳註「每天補到 3 張…」 | **每天補滿3張，過期撕榜，完成提高破曉聲望** | 實機原句 29 字，縮為 20 字（17:27 拍板）。 |
| 按鈕「閒談」「回到街上」 | **沿用** | 實機原文為「閒談」（不是「開談」）。 |

### 風險塊怎麼寫（只使用現有資料）

| 欄 | 有資料時 | 沒有資料時 |
| --- | --- | --- |
| 險級 | 獵殺／清剿：取目的地 `WILDS` 或 `DUNGEONS` 的 `risk`，顯示統一四檔（低／中／高／極高）。多地點時本圖暫取較高檔。 | 收集、送到城鎮：標 **危險 未定**，**待數值設計師**（城鎮與收集沒有險級欄；路線遇襲率是出發當下算的，不存在委託資料裡）。 |
| 失敗後果（一句，≤22 字） | 有期限：一般 **逾期則撕榜**；送貨 **逾期押金沒收**（`questTick`）。 | 長期（無 `due`，如起手「灰髯狼 ×3」）實機不會因逾期撕榜：寫 **失敗罰則未定**，**待數值設計師**。 |
| 不用的 | — | 受傷、聲望懲罰、敵兵具體數值、路線遇襲率——委託物件上沒有這些欄，不編造。 |
