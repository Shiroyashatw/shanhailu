| 項目 | 定名 | 理由（一句） |

| 四種墳 | 無名碑、手寫碑、孩童墓、新墳（全沿用）＋新墳小標「新」 | 都好認；通稱一律用「墳」 |
| 鏟 | **鐵鏟**（原鏟） | 單字太小，易讀成動詞 |

| 動作鈕 | **探墳、挖墳、開棺、取物、回填** | 兩字等寬、動詞開頭；單字「探」會跟既有「探查」「探幽」混 |
