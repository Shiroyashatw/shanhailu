---

## 1. 預設名與解禁

- 預設名維持「沈衡」，視為合法，不攔
- 「滿」「衡」兩字解禁：開局池、NPC 取名庫、玩家自訂名都不因這兩字攔截

---

## 2. 硬規則（開局池、NPC 取名庫、玩家自訂名都適用）

姓 1–2 字、名 1–2 字，合計 2–4 個中文字。只收 CJK 統一漢字。不收空白、符號、英數。

玩家自訂名在 `js/game.js` `nameErrors()` 攔截；提示寫在 `js/ui.js` `NAME_MSG`。error key 與提示：

| key | 提示字串 |
| --- | --- |
| `chars` | 不可使用英數、空白或符號 |
| `length` | 合計須為 2–4 個中文字 |

（現碼兩句句尾有句號，實作時改成上表，不加句號。）

---

## 3. 玩家自訂名：只再擋兩類

只攔**整名**（姓＋名）與清單項**完全相同**。不攔單字，不攔「包含」。

1. 固定角色全名：`虞九淵`、`明夷`
2. 稱謂詞或遊戲名詞，起始詞表見第 5 節

這兩類共用一個 error key 與提示：

| key | 提示字串 |
| --- | --- |
| `taken` | 這個名字已經有人用了 |

以下**不攔**（自訂名不做字面檢查）：滿、衡、單獨的數字字、姓「釋」、「悟」加一個字、性別或輩分字、難字、勢力特徵單字。

---

## 4. 開局池與 NPC 取名庫

撰稿與生成端使用。玩家自訂名**不要**套用本節的「避免」，也不要因此多攔。

| 編號 | 規則 | 處置 |
| --- | --- | --- |
| N1 | 全名等於「虞九淵」「明夷」；名的位置連用「九淵」「明夷」 | **禁用** |
| N2 | 單字「淵」「夷」，以及姓「虞」 | **避免** |
| N3 | 全名或名等於第 5 節稱謂詞 | **禁用** |
| N4 | 名或綽號含性別、輩分字：婆、嫂、娘、叟、翁、伯、叔、姨、姑、嬸、爺、哥、姐、妹、弟、媽、婦、公。只管「名」，不管姓（例如公孫、翁姓） | **禁用** |
| N5 | 名字（名的位置）全由數字字組成，例如張三、李七、王二十。數字字：一二三四五六七八九十百千萬零。姓的位置不管（例如姓「萬」） | **禁用** |
| N5 | 名含數字字、但不是整個名字都是數字 | **避免** |
| N6 | 姓為「釋」；名為「悟」加恰好一個字（「悟X」） | **禁用** |
| N6 | 含佛門用字：禪、佛、僧、慧、覺、淨、空、緣、戒、菩、薩、尼 | **避免** |
| N7 | 全名或名包含第 5 節遊戲名詞（二字以上） | **禁用** |
| N7 | 名含大勢力特徵單字：象、曉、星、鴉、裂、幽、神 | **避免** |
| N8 | 難字、生僻字 | **避免**（細則交 LOC-NPC） |
| N9 | 與現實公眾人物同名同姓 | **禁用** |
| N9 | 與現實公眾人物近音 | **避免** |

「禁用」：庫端不收錄。「避免」：庫端盡量不收，不是玩家端檢查項。
