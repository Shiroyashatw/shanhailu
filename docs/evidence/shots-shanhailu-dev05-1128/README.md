## 逐項差異

**01／02 收合、展開**
1. 數字一致：收入 23／支出 15／淨額 +8／現額 208、繁榮 50 持平、治安 55（與草稿相同，皆讀 `brief`）。
2. 文案照 `city-status-copy-v0.1.csv`：「今日收入23兩」（CSV 無空格、帶「兩」），草稿寫「今日收入 23」。
3. 展開時「現額」放在財庫格內與收支行末，草稿另起一行；為了不加高面板。
4. 展開末行沒有草稿的「官道風險 平常」：SPEC-01 §7.1 沒有這一項、`brief` 也沒有，不自行編造（列待裁）。「交易稅 5%」保留（§4.3 常數）。
5. 草稿的「資助巡邏 100兩」「投資巡邏所」「尚無剿匪委託」三鈕未做：資助與巡邏所的玩家行動屬 DEV-04，投資巡邏所不在第一批（16:46 裁決第 5 項）。
6. 草稿收合條把探查鈕寫「探查 1時」；實機沿用現有「探查（1 小時）」（24 小時制用語，Q6 甲說探查鈕留給後續 HUD 包）。
7. 草稿右欄「平民」、左欄無地面格是 UI-01／DEV-DROP 的範圍，本包不動（左欄地面 10 格仍在）。
8. 平面圖說明句（鎮的簡介）原本在說明列，收合條改成城況後不再顯示；受創／獸潮兩句原文搬到平面圖頂端警示條（對照 03）。

**03 受創求援**
1. 求援條照 CSV「已求援，得銀90兩」；草稿寫「已求援：補貼90兩」。
2. 因果句照 `brief.whyCode`：本次造出的狀態繁榮是回升（P 20 → 23，`trend=up`），所以句子是「繁榮較昨日升，因治安轉好」，箭頭 ↑；草稿是示意組合（README §6 第 5 點已說不是手算）。
3. 數字行照 CSV「較昨日+1」；草稿寫「昨日降」。
4. 紅色只用在荒涼／混亂檔、欠餉／吃緊、求援條與外框（UI-02 README §2「紅色只用於關鍵危險警示」）。
5. 匪勢仍是「零星 30」：DEV-04 之前 B 不動（DEV-02 註記）；草稿示意「猖獗 40」。
