## 使用規則

**任何 bot 要查或改企劃內容，先看這份索引，再找對應的分冊。** 一份分冊只講一個系統，同一段內容只放在一份；其他分冊用連結指過去，不要複製。要改某個內容：先用下面的「查什麼去哪份」找到分冊，只改那一份，必要時同步更新該分冊的版本日期與本索引的「最後更新」。分冊內的「實作註記」是程式的實際做法；與 GDD 不一致的地方統一寫在 [discrepancies.md](discrepancies.md)。

舊檔 `GDD-v0.2.md`、`GDD-v0.1.md`（在 `/workspace/shanhai-sandbox-gdd/`）**已過時**，只當歷史，不要引用。repo 內的 `GDD-v0.2.md`、`GDD-v0.25.md` 也是歷史。
