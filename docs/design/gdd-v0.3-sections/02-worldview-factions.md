## 二、世界觀

### 2.1 核心問題

**「神為什麼不再庇護我們？」**

### 2.2 玩家開局就知道的事

- **天裂之夜**：大陸原由十二生肖神守護，千年太平。那年秋天井水泛紅、鴉群飛離、廟香熄滅，夜空被一道血紅裂縫劈開。
- **十二神墜落**：十二神同夜墜落，砸出十二道裂口，露出地層。神流的血化為血雨與血霧，妖魔從裂口湧出。
- **遠征軍全滅**：各路高手組成遠征軍走進裂口找神，無人生還。當年護民的人，三年後多半成了軍閥與世族。
- **現在**：天裂後第三年。

## 勢力聲望（原 GDD §4.4）

勢力會越來越多（軍閥、邪教、日後各區域的門派），所以介面一開始就照「任意數量」設計：

- **左欄**：可捲動的精簡清單，一行一個勢力（徽記、名稱、門檻進度條、聲望數字），聲望高的排前面。一次看得到 5 個，更多就捲動。
- **勢力總覽**：點清單任一行打開。每個勢力有說明、怎麼漲、各門檻的好處；還不知道的勢力只顯示數量。
- **發現勢力**：有些勢力一開始就知道，有些要讀到相關的見聞才會出現（例如讀到〈軍閥與世族〉才知道鎮西將軍府）。

| 勢力 | 怎麼漲 | 門檻與好處 |
| --- | --- | --- |
| 破曉軍團 | 完成委託板的委託、擊退獸潮、清空地城、上繳軍牌 | 10：校場肯教〈破陣〉。20：委託報酬 +15% |
| 天星商會 | 在商號與行商買賣、完成送貨 | 10：商號九五折。25：買得到精工大囊，鑑定半價 |
| 鴉衛 | 向赤鴉回報見聞、查證傳聞 | 6：赤鴉肯替你辨傳聞。14：傳授〈鴉影〉 |
| 鎮西將軍府 | 讀到〈軍閥與世族〉後出現 | 下一版開放 |
| 拜裂教 | 讀到〈邪教〉後出現 | 下一版開放 |

聲望只增不減（本版）。
