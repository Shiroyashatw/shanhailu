## 十二、待 mumi 拍板

| 項目 | 目前做法 | 想問的事 |
| --- | --- | --- |
| 1. 招式的代價 | 增加疲累＋冷卻 | 要不要另外做「氣力」這種只在戰鬥內的資源 |
| 2. 聲望 | 只增不減 | 要不要做勢力之間的衝突（幫了軍閥，軍團就降） |
| 3. 侵蝕 | 只扣生命上限 | 要不要做成赤鴉那種雙面刃（侵蝕越高，某些能力越強） |
| 4. 見聞錄 | 純收集 | 集滿某一類要不要給獎勵或解鎖暗線事件 |
| 5. 下一個區域 | 未定 | 先開東山（廢廟、更多神的線索）還是南山（火、不同的生態） |

> 此處是 mumi 在 GDD 中提出的待拍板項目；實作與 GDD 的出入另列於 [discrepancies.md](discrepancies.md)，兩者不要混用。目前五項皆未決，程式取「目前做法」欄。
