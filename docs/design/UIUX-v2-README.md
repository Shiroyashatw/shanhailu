## 3. 各欄元件尺寸

### 3.1 左欄（240）
- **人形 10 部位**（x22–226、y14–198）：主手／副手 44×88；胸甲 48×64；頭盔 40×40；手套／靴子 44×40；腰帶 48×22；左右戒 26×26；護身符 28×28。槽內只放 1 字 ICON 代號；左上 6×6 小方塊標稀有度（灰＝良品、黑＝稀有、實心黑＝傳奇；凡品不標）。空槽用虛線＋淡色代號。
- **背包槽**是人形區裡的一個 36×36 ICON（右下數字＝格數）；旁邊 36×36 斜紋虛線格是**馬車槽**，鎖定預留。
- **行囊**（y230）：5 欄 40×40、格距 4。初始 6 格，另外 18 格斜紋虛線格要換大背包才解鎖，最多 24 格；右側 4px 捲動條。
- **地面**（y474）：2×5 暫放格。採集或剝皮放不下的東西、棄物撤退丟下的東西會落在這裡，拖回行囊就能撿起來。
- **近處小圖**（228×104）：同 Underkeep 左下的小地圖；在世界地圖情境可以收合。
- **負重底條**（y684，228×24）：「負」圖示＋108×8 細條（40%／75% 刻度）＋`52/80`＋`×0.82`。

## 4. Hover 提示卡防遮擋規則
1. **裝備／行囊提示卡只出現在左欄**：寬 232，x 10–242，右緣不超過左欄（x≤246），**永遠不跨進中欄（x≥252）**，所以不會擋到戰鬥舞台或敵方意圖。
2. 在被滑過的槽位**正下方**展開，暫時蓋住行囊區；離底部太近就改往上翻。滑鼠移開就關。
3. 卡片內容：名稱 14/700＋右上稀有度標籤；部位・重量；基底數值；**最多 3 條詞綴（不分前後綴、不顯示詞綴等級，數值直接在區間內骰出）**；傳奇另有 1 條專屬機制詞條，用虛線隔開；最底下寫售價、操作提示和與目前裝備的比較。
4. 4 階只換右上標籤和邊框：凡品＝1px 灰、良品＝1px 黑、稀有＝2px 黑、傳奇＝3px 雙線（樣張見 `SHL-v2-02` 圖例下方）。
5. 中欄商品的提示卡錨定在中欄右側的交易欄位置，不會蓋住貨架網格。

## 5. 世界地圖底圖搜尋結果
- 依指示搜過：`/workspace`（全部子目錄，包括 `shanhai*`、各專案的 `assets/`、`art/`、`img/`、`docs/`、`evidence/`）、`/home/box`、`/cursor/stores/`（包含所有 Page 的 assets 與 previews）。
- 用的指令：`find … -iname '*.png|*.jpg|*.jpeg|*.webp'` 過濾檔名含 `map|world|overworld|zone|region|atlas|terrain|地圖|山海|shanhai`；另外列出所有大於 400KB 的圖檔；並查看所有 Page 標題與附件。
- 結果：**找不到任何手繪或像素世界地圖圖檔**。檔名有 map 的都是別的東西：舊專案的戰鬥小地圖、營地截圖、地點清單線框（例如 `/cursor/stores/user/canvases/da74b0f7-…/assets/map-1280.png` 是清單線框，`22bee9a5-…/assets/c1-map.png` 是營地構圖）。這些都已打開確認過，都不是世界地圖。
- 因此本版沿用的是**之前畫過的《山海錄》世界地圖：v1 `/workspace/shanhailu-uiux-draft/SHL-01-main-map.png` 中欄的節點地圖**。9 個節點（渡陰關、安全官道、灰窯鎮、山嶺野徑、青霧藥林、亂葬古窯、赤石廢礦、枯骨獸徑、沉淵祭窟）、8 條連線和相對位置都直接沿用，等比放大（x×1.45、y×2.09），再加上淡色地形區、河線和區名。等像素世界地圖畫好後，直接換掉底圖，節點座標不變。
