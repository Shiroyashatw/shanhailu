FX-05 買賣：購買飛入行囊、銀兩滾動、數字合併　草稿

城鎮建築・天星分號（市集）。峰值幀＝剛按下「買」金創藥水 ×1：貨架格庫存 −1，圖示飛向行囊第一個空格，右欄銀兩 148→136 滾動，舞台右緣跳出「−12 兩」。賣出、連買合併、失敗見圖板。

原則：買賣最重要的資訊是「錢變了多少、東西去了哪」。因此只做三件事：圖示飛入／飛出、銀兩滾動、一個合併後的差值數字；不做金幣噴灑。

參考慣例：Moonlighter 以金幣數字與圖示入包回饋買賣；Stardew Valley 賣出後右上金額滾動。本草稿取「滾動＋單一差值」，不做粒子。
