FX-02 露宿 8 小時：長時流逝進度條＋夜警打斷　草稿

荒野・營火已生。峰值幀＝露宿進行到 4/8 小時：場景暗場（深夜），中央小面板 8 格進度，右欄時段條與鐘點同步前進，疲累／飽食差值數字貼在舞台右緣指向各條。面板不蓋住採集點與營火、不攔截輸入。
