## 1. 用法與現況

| 規則 | 說明 |
| --- | --- |
| 編號 | LOC 本地化、ART 美術、SPEC 規格、UI 畫面、DEV 開發、ACC 驗收、DOC 文件 |
| 規模 | S＝小 PR／短規格；M＝一個完整 PR 或一套畫面；L＝仍一份交辦，必要時可再拆 |
| 負責 | 只從：數值設計師、UIUX設計師、開發工程師、Game Art Director、本地化編輯 |
| 美術三關 | 草稿 → mumi 同意 → 上色 mockup → mumi 同意 → 定稿；不把同一張圖拆成三個交辦 |
| UI 草稿規矩 | 一律白底、灰框、黑字。交件前自己檢查文字有沒有重疊或被切掉。mumi 看過之前不會退回修改。本批 UI 只交到草稿（草稿 → mumi 同意 → 才進上色 mockup） |
| 實作／驗收 | ACC 等該期 DEV 全部回來再派 |
