## 0. 結論（先看這裡）

1. **善惡值 K（−200～+150）是底層**，五段：義名 ≥100｜良善 30～99｜常人 −29～29｜惡名 −99～−30｜兇名 ≤−100。惡行落得快：殺一個良民 −50（一件事一段），殺孩童或無依者 −100（可一口氣掉兩段）；善行積得慢：日常善每天有上限（0.25～1.2），重善每季只計 2 件。**兇名走回義名最快約 233 天（近兩年）**【手算】。
2. **通緝值 W（0–100）是法對惡行的反應**，按管轄分開記：王法（`wang`，灰窯原＝白虎軍）、軍規（`jun`，破曉）；黑水規矩另用追殺值 H（存 `hostility.black`）。四檔：嫌疑 1–19｜通緝 20–49｜重犯 50–79｜死罪 ≥80。**每升一檔至少隔 12 小時並發預兆**，所以從 0 到死罪最快 36 小時，世界不會無預警處死你。
3. **只有被人發現才通緝**：發現率 `p = clamp(0.25 + 0.004·O + 0.10·Geff)`，灰窯起手 0.57、渡陰起手 0.69，城內黑夜 ×0.7【手算】。善惡另算：有人在場就全額算，沒人看見輕一半。
4. **重罪被抓之後，判決用一個加總分數 J（≥5 死刑，否則押前線）**，把藍圖 9.5 的偏死刑、偏前線條件全部量化；只有「兇名＋屠村＋無人保」會被標成 `noExit`（無退路）。待決期 120 小時，期間走得通的退路：逃獄、贖罪、勢力撈人、前線求生；自首在被捕前，是減刑而不是退路。
5. **撈人看派別**（已拍板，不重開）：拜裂教、九幽殿正式成員屠村也撈；黑水盟、窮奇寨不撈屠村；其餘邪派屠村要核心階、一般重罪正式階即可。終融（怪化的終階）不走死刑，走獵令，本包只定交界。

## 3. 善惡值

### 3.1 一件事怎麼算

```
ΔK(惡) = −Base × T × V         Base 由行為表；T 對象係數；V 目擊係數
ΔK(善) = +Base（先過 GOOD_CAP／HEAVY_GOOD，見 3.4）
單件 ΔK(惡) 下限 −100
```

**T 對象係數**（取適用者的最大值，上限 2.0）：

| 對象 | T | 說明 |
| --- | --- | --- |
| 良民 | 1.0 | |
| 有職位者或同伴 | 1.5 | v0.3 改詞（原「命名 NPC」），T 值不變 |
| 弱者（孩童、乞兒、傷病、被縛或被賣的人） | 2.0 | 「救一個無依的人比給乞兒一文錢重」的反面 |
| 守衛、官差、軍士（執法者） | 0.7 | 殺守衛仍比打醉漢重：殺守衛 = 50×0.7 = −35，傷人 = 8×0.7 |
| 勢力的敵人（匪、斷路幫、邪派巢穴敵人、怪物） | 0 | **向勢力的敵人出手不算惡**（藍圖 9.2）；剿匪委託完成才算善 |
| 破曉的人、其他正派的人 | 1.0 | 殺破曉的人是惡 |

**V 目擊係數**：`V = 1`（事件發生時，同場景有任一非同夥 NPC，含被害人倖存、路人、守衛）；否則 `V = UNSEEN = 0.5`。**在場機率** `P_present`：城內街上白天／清晨／黃昏 1.0、黑夜 0.6（路人少，依 SPEC-TIME 店鋪打烊）；店內店員在場 1.0；官道 0.3；野外與地城 0（改由事件指定：商隊有逃出的倖存者＝在場）。**販人事件一律 V=1**（SPEC-03：買主與同夥知情）。**黑市成交一律 V=0.5**（SPEC-03）。

**善行目擊**：善行的受益者在場即 V=1；無人知道的善行 ×0.5（同 UNSEEN）。

### 3.3 為什麼這樣定（設計意圖與目標體驗）

- 一個良民＝一段、一個孩童＝兩段：把「殺良可以一口氣掉兩段」做成**有條件**的（弱者），而不是每次都兩段。從義名殺孩童 −100 → 0（義名→良善→常人，兩段）；從常人殺孩童 → −100＝兇名（常人→惡名→兇名，兩段）【手算】。
- 兩個良民就是兇名（−100）：符合藍圖「兇名＝殺良、販人、血祭的人」。沒人看見的殺良 −25，一次還在常人（−25 > −30）、兩次惡名、四次兇名。
- 目標體驗：玩家**知道自己在往哪走**。`karma.log` 與 UI 顯示每件事的 ΔK 與是否被看見。

### 3.4 善行怎麼積（慢）

```
輕善、中善：ΔK = min(Base × V, GOOD_CAP(K) − goodToday)    // 超出當日上限的部分捨去
重善：     只在「本季已計 < 2 件」時給 ΔK = HEAVY_GOOD(K) × V；超過的重善 ΔK=0（其他獎勵照給）
           同季第 2 件另須與前一件（同季第 1 件）相隔 ≥15 wday（wday − lastHeavyWday ≥ 15），不夠隔的 ΔK=0（Q-K1b 甲，v0.4 16:28 定案）
```

- `goodToday` 每個 `wday` 歸零（05:00）；`heavyCount` 在「重善季」`floor(wday/30)` 變化時歸零。`lastHeavyWday`＝本季最近一件計入的重善的 `wday`（Q-K1b 用；換季歸零，下一季第 1 件不受間隔限制，所以季末第 2 件與下季第 1 件仍可連著拿）。
- K<0 時日常善上限只有 0.25：**一個 −50 的殺良要補回 0，最快 77 天**（補到常人線 −29 約 32 天）。
- 每得到 +x 的善（含重善）：`karma.heavy = max(0, heavy − 0.5·x)`。

**目標體驗與手算**（每日上限、重善全拉滿的**平均速率**手算值；**v0.4（Q-K1 甲）起它是中位數門檻**：200 seed 標準玩法各區間的中位數天數須 ≥ 下表，個別更快的 seed 不算失敗；不再當「任何人都不可能更快」的下限）【手算】：

### 5.2 發現率

```
P = clamp( (0.25 + 0.004·O + 0.10·Geff) × phaseMult × LAW_WEAK(I) × 標記倍率 , 0.15, 0.95 )
  phaseMult：城內黑夜 0.7，其餘 1.0；官道段改用 兩端鎮 P 平均 × ROAD_MULT(0.6)；野外與無管轄 0（不通緝）
  標記倍率：顯性標記者 1.25；renlu.cover_guan 且在王法管轄且買主＝白虎軍 ×0.5（SPEC-03）
偷竊：成功 P×0.3、失敗 1.0。殺人滅口（現場所有目擊者都被殺）：P×0.3
```

**【手算】** 灰窯起手 `O=55, Geff=1`：P = 0.25+0.22+0.10 = **0.57**；黑夜 0.57×0.7 = **0.40**。渡陰起手 `O=60, Geff=2`：0.25+0.24+0.20 = **0.69**；黑夜 0.48。`S_PUB(灰窯起手)=0.57/0.57=1.00`（與 SPEC-03 預設 1.0 一致）；渡陰 = 0.69/0.57 = 1.21。官道段不另給起手值：取兩端鎮當日 P 的平均再 ×0.6（例：兩端各 0.57 → 0.34）。

**偷竊檢定**（Q6 甲已定：`steal` 熟練度第 3 期解鎖，現況 `locked:true` 改為開放）：`p_success = clamp(0.30 + 0.03·(身法−10) + 0.006·偷竊, 0.05, 0.85)`；成功得 5–15 兩或一件雜物（並依來源寫 `mark`）。

### 5.4 升檔預兆與消退

**升檔規則**（解決「通緝一路升級，每一步都有預兆」）：

```
tierRaw = 由 W 與 felony 推出的檔（非 felony：最高 3）
首次升檔立即；其後每升一檔，要距離「上一次升檔」≥ TIER_GAP_MIN（720 分鐘）才生效
tier = min(tierRaw, tier + 1)，在 time.hour 事件檢查
```

**【手算】** 屠村一次 W 直接 100：t0 嫌疑、t0+12h 通緝、t0+24h 重犯、t0+36h 死罪；玩家至少有 36 小時逃、自首、找人撈。降檔不受間隔限制（W 降了立刻降）。

**消退**（每個 `wday` 一次，05:00）：

```
離開該管轄：W −= DECAY_LEAVE(Gmax)   （2.5 − 0.5·Gmax：Gmax=0→2.5、1→2.0、2→1.5、3→1.0）
留在管轄內：W −= DECAY_LEAVE / 2
收押、待決、前線期間不衰減
felony 旗標在 W ≤ 19 時清除
```

**【手算】** 王法（灰窯原 `Gmax=2`）：從 W=49 躲到 19 要 (49−19)/1.5 = **20 天**，再到 0 還要 19/1.5 ≈ **13 天**，合計 33 天。留在管轄內時每天只 −0.75（40 天才降一檔）。

### 5.5 賞金與賞金獵人

- **賞金**：`BOUNTY(W) = W²/10` 兩（W=20→40、50→250、80→640、100→1000）【手算】。**實付**由該鎮財庫 `T` 支出：`min(BOUNTY, T)`；付不出的部分不影響獵人積極性（無旗營合約）。罰金與贖金回財庫。
- **獵人遭遇率**（`tier≥3` 的管轄內或其官道段；荒野 ×0.5）：每段行程 `HUNTER_P = clamp(BOUNTY/800, 0.10, 0.60)`。**【手算】** W=50 → 0.31；W=64 → 0.51；W≥72（BOUNTY≥576）起封頂 0.60。先判獵人，再判既有野徑遇險。
- **獵人編制**：重犯檔 3 名、死罪檔 4 名＋精銳 1 名，皆從**生成獵人池**取（v0.3 改詞：名字由系統生成，不再待本地化命名；人數不變）。每名獵人狀態 `ready｜away(backT)｜dead`。
- **遭遇選項**：① **談判**：`p = clamp(0.3 + 0.008·說服 + 0.05·(口才−10) − 0.005·W, 0.05, 0.90)`（沿用 `game.js:1720` 的現行形狀，加通緝扣減）；成功＝該獵人 `away` 7 天。② **收買**：`ceil(0.25·BOUNTY)` 兩，成功率 0.85，同 `away` 7 天（兇名者 ×1.5 價）。③ **迎戰**：獵人數值【暫】——重犯檔：生命 45、傷害 6–9、護甲 3、速度 11（約逃兵×1.5）；死罪精銳：生命 70、傷害 8–11、護甲 5（約遠征亡卒×1.4）。擊退（獵人逃）＝`away`；擊殺＝`dead`，`hostility.wuqi += 30`（無旗營記仇），**不加 W、不算殺良**（拒捕、賞金獵人屬自衛）。④ **逃跑**：沿用撤退率。⑤ **投降**＝被捕（走第 9 節）。
- 死亡的獵人每 15 個 `wday` 補一名（至多補到編制人數）。**【待雲端驗算】** 獵人戰力與勝率、遭遇率是否讓重犯玩家無法離境。

### 5.6 通緝擴散（王法 ↔ 軍規）

僅限軍規辦的罪（傷人、殺良、通邪、販人、血祭、傷官）：在一個管轄被發現後，**隔一個 `wday`** 對方管轄收到 `ΔW × 0.5`（百衲會乞兒傳話，v0.2 §3.4）。偷竊、走私、逃稅不擴散。【暫】

### 5.7 城內扒手（X-i 甲：兩包以本節為準，SPEC-01 v0.4 §5.11 引用）

觸發：玩家進城鎮，且該鎮今日 `O < 35` 時，每個 `wday` 第一次進店前判定 `p = 0.05`；中則被扒 `rnd(10,20)` 兩，且不超過身上銀兩的 25%。事件 `pickpocket_victim`：不影響 K、不加 W；日誌提示「治安差」。這讓 `O` 的下降對玩家有可感後果，又不增加追逐系統。【暫】灰窯起手 `O=55`，不觸發。

## 6. 盤查流程（說服、賄賂、拋貨逃走、戰鬥）

**觸發**：① SPEC-03 的 `checkpoint_seized`（稅卡）、`raid_seized`（鬼市突查）、`informer`（眼線）；② 販人 `p_expose` 命中（SPEC-03 8.4）；③ 嫌疑檔進王法或軍規城鎮，且身上有「有記號未洗」或違禁品，機率 0.5（`felony` 在身者 1.0）；④ 通緝檔進城的罰金與搜查。身上沒有違法物也沒有重罪案卷，嫌疑檔直接放行。

**先算待加罪** `pending`：列出這次會成立的罪與 `ΔW_pending = Σ ΔW`（5.1 表）；販人暴露＝販人（＋拜裂教單加通邪），`felony=true`。

| 選項 | 條件 | 成功率／價格 | 成功 | 失敗 |
| --- | --- | --- | --- | --- |
| 1 接受搜查 | 永遠可 | — | 沒收（SPEC-03 規定：全部違禁與記號物）；`pending` 全加 W | — |
| 2 說服 | 記號被原主認出時**不可選** | `p = clamp(0.3 + 0.008·說服 + 0.05·(口才−10) − 0.004·ΔW_pending − 0.15·[felony], 0.05, 0.90)`（形狀沿用 `game.js:1720`）；`gainProf('shuo')` | 放行，貨保留，不加 W | 轉成選項 1，另加「妨礙」+5 |
| 3 賄賂 | **只有王法管轄；非重罪；通緝檔 ≤2** | 價 `ceil(1.5·ΔW_pending)` 兩；成功率 0.85 | 放行，貨保留，不加 W | 錢沒收，轉選項 1，加「妨礙」+5 |

## 7. 城門與入城

### 7.1 入城規則（`gate(town, jur, tier)`）

| 檔 | 規則 |
| --- | --- |
| 0 | 自由 |
| 1 嫌疑 | 盤查（有違法物才盤，見第 6 節③）；顯性標記者最低視為嫌疑（`tier = max(tier, 1)`） |

### 7.2 潛入

`p_sneak = clamp(0.25 + 0.03·(身法−10) + 0.004·閃躲 + 〔phaseOf==='night' → +0.20〕, 0.10, 0.70)`，死罪檔 ×0.5。**【手算】** 身法 10、閃躲 10：白天 0.29、黑夜 0.49；死罪檔 0.145／0.245。失敗：重犯檔＝盤查選項 4、5 可用（拒檢 +10）；死罪檔＝逮捕選項（7.3）。

成功後在城內是「潛伏」：每小時判定一次被發現 `p_spot = 0.15 × S_PUB × phaseMult`（重犯檔）或 `0.30 × S_PUB × phaseMult`（死罪檔）；命中同潛入失敗。**黑水管轄（鬼市、後巷）內不判定**。【暫】

### 7.3 見面即捕與拒捕（死罪檔）

守衛、巡邏、獵人與玩家同場景時，出現選項：**束手就擒**（逮捕，第 9 節）｜**拒捕**（入戰，守衛 `min(3, Geff+1)` 名；擊倒守衛記傷官重罪；玩家生命歸零＝永久死亡，死因「死於拒捕」）｜**逃跑**（撤退率）。**不直接格殺**（v0.2 #7）。重犯檔守衛只驅離，不逮捕，除非玩家選戰鬥。

## 8. 消除通緝

### 8.1 繳罰金

王法管轄、通緝檔 ≤2、進得了城：付 `PAYOFF = 0.5×BOUNTY(W)`，王法 W 歸 0。**【手算】** W=20 → 20 兩；W=49 → 120 兩（約古窯清理委託兩單）。軍規不收罰金（靠功抵過）。

### 8.2 坐牢（輕罪案）

## 9. 逮捕與判決

### 9.1 什麼時候逮捕

① 死罪檔見面即捕且玩家選束手就擒（7.3）；② **自首**（9.4）；③ 盤查時有重罪、選接受或失敗（第 6 節）；④ 投降（賞金獵人遭遇選項⑤）；⑤ 前線逃跑被抓回。**非重罪、且 W<80 的失敗只加 W，不逮捕。**

### 9.2 案卷 `S.case`

```
S.case = {
  id, jur,                          // 'wang' | 'jun'
  t0,                               // 逮捕時刻（S.t 分鐘）
  charges: [ids],                   // 5.1 的罪
  felony, massacre, victimNoble,    // 重罪、屠殺級、被害人含官員或大戶
  nKill,                            // 殺良被害人數
  renluTier,                        // 逮捕時 renlu.tier（0–4）
  captives: false,                  // 人贓並獲
  surrender: false,                 // 自首
  wcase,                            // 逮捕時該管轄 W（贖罪、撈人定價用）
  sponsors: [rescue ids],           // 判決時可用的撈人管道（11 節）
  J, verdict,                       // 'jail' | 'front' | 'death'
  pendEnd,                          // 待決終點（S.t 分鐘）
  noExit, fugitive, rescue
}
```

### 9.3 判決 J

**輕罪案**（`felony=false`）：`verdict='jail'`，8.2。**重罪案**依下式；**判決在逮捕當下一次算定**，之後只有退路能改。

```
J = Jk + Jcrime + Jvictim + Jsponsor + Jself + Jfight + Jrenlu + Jjur
Jk       兇名 +3｜惡名 0｜常人以上 −1
Jcrime   min(3, nKill) + 3·[血祭] + 3·[massacre] + 2·[販人]
Jvictim  被害人含官員或大戶 +2（一次）
Jsponsor 可用撈人管道數 = 0 → +2；≥1 → −2
Jself    自首 −3
Jfight   任一武藝熟練度 ≥25（邊關缺戰力）−1
Jrenlu   販人者：tier3（掌帳）+2、tier4（分櫃）+3；人贓並獲 +1；同案販人 ≥3 次 +1
Jjur     白虎軍 0；朱雀軍 −1（4.2）
verdict = (J ≥ 5) ? 'death' : 'front'
```

**軍規管轄**（破曉）：重罪案預設 `front`（藍圖 12.8「一律發往最前線、戴罪立功」）；例外 ① 殺破曉軍士、前線臨陣脫逃＝`death`（斬）；② 販人 `renluTier ≥ 3`（主事者）改用上面的 J。（Q5 甲已定）

**`noExit`**＝`verdict=='death'` 且 `karma.tier=='xiong'` 且 `massacre` 且 `sponsors` 為空（藍圖 9.5：只有「兇名＋屠村＋無人保」沒退路）。`noExit` 時：撈人、贖罪、買通、越獄都關閉；待決期仍照走。

**目標體驗**：判決不是擲骰，玩家在逮捕前就能算（UI-03 可在判決書上列出 J 的各項）。**【手算】**（`sponsors` 以 0 起算）：

| 案例 | J 的組成 | J | 判決 |
| --- | --- | --- | --- |
| 惡名（K=−60）殺良×1、能打、無人保 | 0+1+0+2+0−1 | 2 | 前線 |
| 兇名（K≤−100）殺良×2、無人保 | 3+2+2 | 7 | 死刑；有 1 條撈人路 → 3，前線 |
| 惡名殺良×1，被害人是官員、無人保 | 0+1+2+2 | 5 | 死刑（非兇名，**贖罪仍可用**） |
| 同上＋自首 | 5−3 | 2 | 前線 |
| 兇名屠村（殺良 5 → `min(3,5)=3`，屠殺 3）、無人保 | 3+3+3+2 | 11 | 死刑，**`noExit`** |
| 把風被當場抓（惡名 −32、販人、無人保） | 0+2+2 | 4 | 前線（藍圖：第一次多半還不到死刑） |
| 押手、惡名、人贓並獲、無人保 | 0+2+2+1 | 5 | 死刑（藍圖：人贓並獲偏死刑或前線） |
| 掌帳、兇名、有九幽殿派保 | 3+2−2+2 | 5 | 死刑，但有撈人路 |
| 分櫃、兇名、有派保 | 3+2−2+3 | 6 | 死刑，有撈人路 |

### 9.4 自首

在王法的鎮衙（`huiyao`）、關樓（`dy_tower`）、或重犯檔的城門口；軍規在破曉營。條件：該管轄 `W ≥ 1` 或 `charges` 非空。效果：`Jself −3`；輕罪案照 8.2；重罪案進判決。**自首是被捕前的減刑，不是待決期內的退路。**

## 10. 待決、死刑、押前線、退路

### 10.1 時間線

```
逮捕 → 判決（當下）→ 待決 PEND_H → 執行
  王法 death 120h｜王法 front 48h（之後押送）｜軍規 death（斬）48h｜軍規 front 24h
```

- 玩家在**牢**（王法：鎮衙牢，`huiyao`；渡陰關：守關營房牢，GD-31；軍規：破曉營牢）。判決書顯示：玩家自取的名字、罪名、判決、執行時刻（來自 `pendEnd`）。
- **倒數預告**：執行前 24、6、1 小時各一則日誌與 UI 倒數。**執行發生在第一個 `time.slice` 使 `t ≥ pendEnd` 時**（睡覺、快轉都不能跳過預告：預告在 `time.hour` 觸發，快轉每小時停一次）。
- 世界照常走（SPEC-01 日結照跑）；**衰減停止**。

### 10.2 牢內規則

- 牢飯：每個 `wday` 08:00 與 18:00 各一餐，飽食 +35（等同標準日 2 餐，SPEC-TIME 不進警示）；寒意以 `indoor` 結算；傷口照常回復。**牢內不會餓死、凍死**。
- 可做：睡、見訪客、逃獄、買通獄卒、贖罪（付款）、讀見聞。不能：買賣、接委託、出牢。
- **訪客**：每個 `wday` 08:00（白天起）對每條可用撈人管道觸發一次「訪客」事件（11 節）。`noExit` 時只有遺言與墓誌銘預覽（演出）。

### 10.3 死刑

待決終點：`die('伏法')`，墓誌銘寫「伏法」；永久死亡照舊（`wipeSave()`）。除 `noExit` 外，**死刑之前一定有人能伸手**（10.4）。判決書、告示、墓誌銘都寫玩家自取的名字。

## 13. 手算驗證（只用算式，不是模擬結果）
