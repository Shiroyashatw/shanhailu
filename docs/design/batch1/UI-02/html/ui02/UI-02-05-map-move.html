螢幕用詞作「負重」（與 GDD、左欄、撤退列「負重 ×M」一致）。格子裡的 ×1.08 卻不是重量本身，而是 speedMult()：hours = ceil(基礎時數 / speedMult())。由負重檔位倍率 × (1+速度詞綴%) 算出，力竭（疲累過高）時再打折。輕裝倍率為 1，大於 1 代表比基準更快。此點須向 LOC 與數值說明，見 wording-map-commission.md。
