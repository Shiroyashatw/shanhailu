# 場景與地圖的畫法

城鎮平面圖、荒野、地城、戰鬥背景、區域圖、大陸圖，都是程式在載入時畫出來的。和精靈不同，場景太大不能手寫每一格，所以改成「用函式在低解析度像素緩衝上畫」。

## 1. 檔案與登記

| 檔案 | 內容 |
| --- | --- |
| `js/scenes.js` | 基礎場景：舊版城鎮側視圖、三個荒野、兩個地城、野徑 |
| `js/scenes_town.js` | 六個聚落的平面圖，以及每棟建築的點擊範圍與路人站位 |
| `js/scenes_map.js` | 區域圖、大陸圖、腐骨沼與野徑岔口兩個荒野、酉神裂口與無名古塚兩個地城 |

- 每張場景用 `.sc-<id>` 這個 CSS class 顯示，例如 `wild_qingwu`、`dg_liekou`、`plan_huiyao`、`map_region`。
- 新場景放進最接近的那個檔案。要開新檔時照 `scenes_town.js` 的寫法：檔案自己完整（輔助函式複製過去）、注入自己的 `<style id="...">`、用「包一層」的方式擴充 `window.SHL_SCENES`（`has`、`list`，以及 `buildings`、`spots`、`regions` 這些資料都要合併保留），並在 `index.html` 裡排在其他場景檔之後。
- 沒有瀏覽器時（Node 測試）要直接 `return`：開頭寫 `if (typeof document === 'undefined') return;`。

## 2. 基本做法

1. **原生解析度＝顯示大小的一半**。顯示時放大 2 倍並用 `image-rendering: pixelated`，所以一個原生像素是螢幕上 2×2 的方塊。常用尺寸：

   | 用途 | 原生 | 顯示 |
   | --- | --- | --- |
   | 城鎮平面圖 | 398×260 | 796×520 |
   | 荒野 | 398×202 | 796×404 |
   | 地城、戰鬥背景 | 398×250 | 796×500 |
   | 區域圖 | 398×280 | 796×560 |
   | 大陸圖 | 340×270 | 680×540 |

2. **自己管像素緩衝**：`createImageData` 拿到 `D`（RGBA 陣列），用整數矩形把顏色寫進去，最後 `putImageData`、`toDataURL`，組成 CSS 規則注入。不要用 canvas 的漸層、模糊、文字、反鋸齒路徑，那些會讓像素邊緣糊掉。
3. **固定亂數種子**：每張場景用自己的種子（`rng(1505)`），每次載入畫出來一模一樣。
4. **暗、低對比**：介面的名牌、按鈕會疊在場景上，羊皮紙色的字要讀得到。場景主體用 `#0f0e0c`–`#3d3a36` 這一帶的暗色，只在重點處用暖光（燈籠、爐火、血霧）。
5. **光從左上來**，和精靈一致。
6. **全部原創**，不照著任何現有圖描。

## 3. 常用的畫圖函式

在 `js/scenes.js` 開頭（其他場景檔各有一份副本）：

| 函式 | 作用 |
| --- | --- |
| `R(x, y, w, h, 色, 透明度)` | 填一個矩形，所有東西的基礎 |
| `P(x, y, 色)` | 點一個像素 |
| `Dz(x, y, w, h, 色, m)` | 網點混色：m＝1、2、3 分別是 25%、50%、75%。用來做兩種顏色之間的過渡，取代漸層 |
| `bands(x, y, w, h, [色...])` | 上下分層的色帶，交界自動加網點過渡。天空、遠山、霧 |
| `E(cx, cy, rx, ry, 色)` | 實心橢圓：樹冠、石頭、光暈 |
| `L(x0, y0, x1, y1, 色)` | 像素線 |
| `S(x, y, rows, pal)` | 把一小段手寫像素格蓋上去（跟精靈同樣的字元格式），用來放燈籠、罈子、小人這些重複的小東西 |
| `rng(種子)` | 固定種子亂數 |

場景檔裡還有很多組合好的函式可以直接借：屋頂 `roof`、木牆 `twall`、窗 `win`、燈籠 `lantern`、木箱 `crate`、木桶 `barrel`、麻袋 `sack`、霧帶 `mist`、煙 `smoke`、岩石 `rock`、`crag`、樹幹 `trunk`、灌木 `bush`、礦坑口 `adit`。新場景先找現成的，不要從頭寫。

## 4. 版面規則（介面會疊在上面）

畫之前先確認介面會在哪裡放東西，那些地方要畫得「安靜」（暗、少細節）：

- **城鎮平面圖**：左上 0–210×0–36（地名）、右上 630–796×0–36（離開鈕）要暗。每棟建築的點擊範圍上方要留至少 22px 空白放名牌。建築之間不重疊，大小約 90–190 寬、70–150 高。路人站位離建築和彼此至少 30px。
- **荒野**：採集點標記（44px 圓圈）和營火位的位置要是空地或矮草，不要放樹幹或建築。
- **地城、戰鬥背景**：敵人站在中央（顯示座標 x 150–650、y 160–440），這一帶要比較暗、比較平，細節放在四周和上方。
- **區域圖**：地點圖示（38×38）和名牌（68×18，在圖示下方 23px）會疊在每個地點上。地點附近的地形要表現「這裡是什麼」（窯、林、礦、沼），但不要畫道路和建築，也不要寫字。左上 0–270×0–34 放圖例，要暗。
- **大陸圖**：區域名牌（約 70×20）放在各區旁邊的空地；海外、大荒的名牌要放在海上或黑暗裡。

座標改了要同步：建築點擊範圍放在 `SHL_SCENES.buildings[場景 id]`、路人站位放在 `SHL_SCENES.spots[場景 id]`、大陸圖名牌位置放在 `SHL_SCENES.regions`；區域圖上的地點座標則在 `js/data.js` 的 `NODES`。改了一邊就要改另一邊。之前發生過地點座標已經左右翻轉、底圖卻沒翻的錯，地點全部落在錯的地形上。

## 5. 各類場景的要點

- **城鎮平面圖**：斜俯視（看得到屋頂也看得到正面牆），不要畫成側視圖。要有街道、廣場、圍牆或柵欄，以及能看出是什麼店的道具（招牌旗、爐火、藥架、酒罈、兵器架），不寫字也要認得出。
- **荒野**：遠景一層、中景一層、地面一層；用霧帶拉開層次。
- **地城**：拱頂、壁龕、地面三部分。光源（燈、血光）放在兩側或深處，讓中央暗下來給敵人站。
- **區域圖**：像古地圖的墨色地形：山用一簇簇小山形、林用樹團、水用暗藍、沼用黑綠夾蘆葦點。整體暗，地點之間的空地不要太花。全圖最亮、最戲劇化的只有一處（目前是西南角的酉神裂口）。
- **大陸圖**：同心圈結構：中山、四山、海外、大荒；邊緣用暗角收邊。

## 6. 驗證

1. 寫一個暫時的預覽頁（放在 scratchpad，不要放進 repo），載入場景檔，把場景以顯示大小排出來；平面圖再疊一層除錯框（建築範圍、名牌位置、路人站位、保留區）。用 Playwright 截圖後，以 Read 工具親眼看。
2. 寫斷言檢查：id 都在、建築範圍在畫面內且互不重疊、不碰保留區、路人站位數量與距離符合規則、舊的場景 id 還在。
3. 量載入時間：每個場景檔總共應在 250ms 內。
4. 至少看兩輪、改兩輪。建築認不出是什麼、平面圖看起來像側視圖、名牌底下太花，都要重畫。
5. 在遊戲裡截一次圖確認，再跑 `node tests/e2e.js`。
6. 老實回報最弱的是哪幾張。
